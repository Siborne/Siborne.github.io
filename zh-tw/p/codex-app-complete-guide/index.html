核心要點概括

  • Codex APP 是目前最強的 Codex 產品型態，免費額度高、功能全、不封號不限速
  • 沙箱機制：OS 級安全隔離，預設禁止訪問沙箱外檔案和聯網，三檔權限可選
  • 多專案並行：多專案、多對話同時跑，物理隔離互不干擾
  • 計劃模式：先對齊再執行，避免 AI 理解偏差導致大量返工
  • Git Worktree：分支級並行開發，不同資料夾真正隔離
  • Skills/MCP：可重複使用專業能力包 + 標準化外部工具接入
  • 定時自動化：外掛 + 定時任務 + MEMORY 經驗積累，越用越穩

為什麼選 Codex APP？

Codex 有四大產品型態，而 Codex APP 是目前最強的一個。相比 Claude Code：

  • 額度更高，免費帳戶也能用
  • 功能更全，內建瀏覽器、畫圖、外掛市集、定時任務
  • 不會限速、封號、降智
  • 上手更快，安裝即用

本文按 12 個章節，逐一拆解 Codex APP 的全部功能。

一、安裝與初始化

準備工作

安裝 Codex APP 前需要先裝好三件套：

  • Git
  • Node.js
  • VS Code

安裝步驟

  1. 前往 Codex 官網 下載安裝包（支援 Windows / Mac）
  2. 一路下一步完成安裝
  3. 啟動後選擇 ChatGPT 帳戶登入（免費帳戶即可）
  4. 首次進入選擇你希望 Codex 處理的工作類型，Codex 會根據選擇預裝對應外掛和 Skills
  5. 選擇主要使用場景：程式設計 / 日常工作
  6. 點擊初始化沙箱

Mac vs Windows：功能基本一致，唯一差異是 Computer Use（自動操作電腦）目前僅 Mac 支援。

二、基礎使用

三欄佈局

Codex APP 採用經典三欄佈局：

  • 左側：任務列表（專案 + 對話）
  • 中間：對話視窗
  • 右側：多功能區域（瀏覽器、終端、檔案樹等）

專案管理

透過「新增專案 → 使用現有資料夾」把本機資料夾註冊為 Codex 專案。每個專案獨立管理對話，互不干擾。

並行任務

Codex 支援多專案、多對話並行執行。任務列表中用圖示標識狀態：

  • 🔵 藍色小點 → 已完成
  • 🟢 綠色標籤 → 等待批准
  • 🔄 轉圈圖示 → 正在執行

對話管理

  • 新對話：Ctrl + N（Win）/ Cmd + N（Mac）
  • 搜尋歷史：Ctrl + G / Cmd + G（僅搜尋標題，不搜尋內容）
  • 歸檔/還原：點擊歸檔按鈕移除對話，在「設定 → 已歸檔對話」中可還原
  • 標題自動生成：每個對話標題由 AI 根據內容自動摘要，也可雙擊重新命名

權限系統：沙箱機制

Codex 的權限系統全部圍繞**沙箱（Sandbox）**展開，這是 Harness Engineering 概念的典型工程實現——用作業系統級別的機制，把 AI 的能力約束在可控範圍內。

預設限制：

限制 說明
沙箱內檔案 預設直接讀寫，不需要逐檔案審批
沙箱外檔案 禁止訪問
聯網 預設禁止

這兩條硬性限制不是靠模型自覺，而是透過作業系統底層機制實現的（Mac 用 Seatbelt/Sandbox，Windows 有對應機制）。

三個權限檔位：

檔位 說明 推薦
人工審批 每次提權都需要手動確認 最安全但繁瑣
自動審查 小模型自動審查低風險操作，高風險才人工確認 ✅ 推薦
完全訪問 無視沙箱限制，可執行一切操作 ⚠️ 慎用

當 Codex 需要訪問沙箱外檔案或聯網時，會發起「提權（Escalate）」申請。

上下文管理

  • 右上角圓圈顯示當前上下文使用量
  • 超出限制時 Codex 自動壓縮歷史對話
  • 也可以輸入 /compact 手動觸發壓縮
  • 經驗法則：清空 > 壓縮。完成一個任務後開新對話，讓 AI 注意力集中

模型選擇

  • 根據任務複雜度選擇思考強度
  • 一般用最新模型（如 ChatGPT 5.5）
  • 快速模式：提速 50%，但消耗 2 倍額度

額度檢視

「設定 → 剩餘額度」中可以看到兩個限額：

  • 5 小時限額
  • 週限額

任一到達上限即暫停使用，到重置時間後自動恢復。

三、畫圖

Codex 內建 GPT Image（當前最強 AI 生圖模型），可以直接在對話中生成圖片。

典型用法：

  • 生成網頁配圖、輪播圖
  • 根據截圖標註位置生成風格化地圖
  • 保持多張圖片的風格一致性

Steer（引導）功能

當 AI 執行方向跑偏時，不要讓它繼續錯下去。點擊對話中的引導按鈕（或按 Ctrl + Enter），中途接管方向盤，糾正 AI 的執行方向。

設定中可選擇新指令是「排隊」還是「直接引導」，推薦預設排隊 + 需要時手動點引導按鈕。

四、計劃模式

對於所有複雜任務，建議先開啟計劃模式（Plan Mode），確保和 AI 對齊顆粒度。

工作流程：

  1. 在對話視窗點擊加號 → 開啟「計劃模式」
  2. 輸入需求，Codex 會先用問題卡片跟你溝通細節
  3. Codex 輸出完整工作計劃
  4. 你審閱確認後，點擊「實施此計劃」
  5. Codex 執行並自動在右側開啟內建瀏覽器驗證

計劃模式的價值：避免 AI 理解偏差導致大量返工，尤其適合架構遷移、大功能開發等任務。

內建瀏覽器 + 批註

  • 右側多功能區可開啟內建瀏覽器預覽專案
  • 點擊「批註」按鈕，選中頁面元素新增評論，AI 會據此修改
  • 修改過程即時可見

五、程式碼管理

Codex APP 不是傳統 IDE，不提供完整程式碼編輯功能。推薦配合 VS Code 使用。

Git 初始化

讓 Codex 把專案初始化成 Git 倉庫：

  • 自動建立 .gitignore，排除不需要的檔案
  • 初始化完成後右上角出現 Git 相關按鈕

配合 VS Code

點擊右上角 VS Code 按鈕一鍵開啟專案，也可以在設定中指定預設 IDE。

GitHub 同步

讓 Codex 幫你在 GitHub 建立倉庫並推送程式碼，所有 Git/GitHub 操作都可以用對話完成。

進階技巧一：對話分叉 + Git 回滾

當你後悔某次改動，想「當作無事發生」：

  1. 對話分叉（Fork）：在對話中找到改動前的位置，點擊分叉按鈕 → 派生到本機，得到一個不含改動的對話副本
  2. 程式碼回滾：在 VS Code 的 Source Control 中複製目標 commit hash，讓 Codex 把程式碼回退到該狀態

分叉只回滾對話歷史，程式碼需要單獨透過 Git 回滾。兩者配合實現對話 + 程式碼的完全回滾。

進階技巧二：Git Worktree

Worktree 本質是用 Git 建立新分支，並把分支程式碼複製到獨立資料夾，實現多分支並行開發。

使用場景：

  1. 右鍵專案 → 建立永久工作樹（如 customer-rating、store-info）
  2. 在不同工作樹中並行開發不同功能，互不干擾
  3. 開發完成後，分別合併回主幹
  4. 移除臨時工作樹

Worktree 的核心價值：不同分支位於不同資料夾，真正做到物理隔離的並行開發。

六、雲端執行

當手邊沒有電腦，或想讓任務在後臺雲端執行時：

前提條件：程式碼已同步到 GitHub。

操作流程：

  1. 推送本機程式碼到 GitHub
  2. 執行模式選擇「關聯 Codex Web」
  3. 點擊「前往 Cloud」，輸入倉庫名和需求
  4. Codex 初始化雲端環境 → 下載程式碼 → AI 分析 → 完成修改
  5. 點擊「建立拉取請求」→ 程式碼以 PR 形式提交到 GitHub
  6. 稽核透過後在 GitHub 上 Merge
  7. 回到本機 Sync Changes 同步最新程式碼

最佳場景：出門在外，用手機審批，讓 Codex 雲端完成任務。

七、記憶系統

每次新對話，AI 對專案的記憶都是空白的。複雜專案需要記憶系統來避免重複交代。

方式一：專案級 AGENTS.md

在專案根目錄建立 AGENTS.md 檔案，每次對話自動作為上下文注入。

可以手寫，也可以讓 Codex 通讀專案後自動生成：

1

讓 Codex 通讀當前資料夾，把學到的專案知識儲存到 AGENTS.md

方式二：全域 AGENTS.md

「設定 → 個性化 → 自定義指令」中編輯，對所有專案生效。

檔案位置：C:\Users\<使用者名稱>\.codex\AGENTS.md

實用示例——防止誤刪檔案：

1
2

禁止使用指令碼批次刪除檔案或目錄，只能使用 Remove-Item 一個一個刪除。
如果必須批次刪除，應停止操作，讓使用者手動處理。

實驗性功能：啟用記憶

設定中的「啟用記憶」可以從聊天中自動提取記憶並帶入新對話，目前仍是實驗性功能。

八、外掛與自動化

外掛市集

左側邊欄 → 外掛，分為兩類：

類型 說明
外掛 第三方服務的能力注入（GitHub、Gmail、Netlify 等）
技能（Skills） 帶目錄的專業能力說明書

示例：GitHub + Gmail 聯動

  1. 安裝 GitHub 外掛和 Gmail 外掛
  2. 授權登入
  3. 輸入：/github 檢視我 star 數前十的開源專案 + /gmail 發郵件給我自己做摘要

定時自動化

把上述流程做成定時任務：

1

把上述工作做成自動化，每週五下午四點發郵件給我

建立後可在「自動化」面板中：

  • 編輯執行頻率（每週/每天/每小時）
  • 切換模型（簡單任務用迷你模型即可）
  • 點擊「立即執行」測試

執行過程中積累的經驗會寫入 MEMORY.md，幫助下一次執行更穩定。

更多自動化玩法

配合瀏覽器自動化或 Computer Use：

  • 每天彙總 Teams 聊天記錄發工作日報
  • 定時開啟網站簽到
  • 定期抓取資料生成報告

九、Skills

Skills 是給 AI Agent 的專業技能包，本質上是帶目錄的說明書。把工作流、專業能力、規範封裝成 Skill，讓 Agent 執行特定任務時更穩定高效。

三種安裝方式

1. 官方 Skills

外掛市集中直接安裝。例如 Remotion：讓 AI 用程式設計方式建立動畫影片。

十、MCP

MCP（Model Context Protocol）是大模型的標準化工具箱，讓 AI 能與外部服務互動。

入口

「設定 → MCP 伺服器 → 新增伺服器」

示例：Supabase MCP

Supabase 是開源免費的 PostgreSQL 雲資料庫。

  1. 在 Supabase 建立專案 → Connect → MCP 客戶端 → 選擇 Codex → 複製 URL
  2. Codex 中新增 MCP 伺服器，傳輸方式選「流式 HTTP」，填入 URL
  3. 終端執行 codex mcp login supabase 完成授權
  4. 重啟 Codex

之後就可以用對話操作資料庫：

2

使用 Supabase MCP 建立一個預約業務表，
使用者的表單資料從後端用 connection pool 方式寫入

十一、電腦自動化（Computer Use）

⚠️ 目前僅 Mac 支援

安裝 Computer Use 外掛後，Codex 可以直接操作你的電腦：

  • 開啟聊天軟體找到老闆發訊息
  • 開啟瀏覽器檢視 GitHub 看板，彙總專案進度
  • 生成英文簡報傳送給老闆

特點

  • 使用虛擬滑鼠後臺執行，不佔用當前視窗
  • 可以編製成定時自動化任務（如每天下午五點自動發簡報）
  • Mac 上建議開啟「執行時防止系統休眠」
