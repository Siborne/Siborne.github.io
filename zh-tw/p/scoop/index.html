為什麼使用 Scoop

Scoop官網網址

在 Windows 下，搭建開發環境一直是一個複雜且困難的問題。由於沒有一個統一的標準，導致各種開發環境的安裝方式差異巨大，需要付出很多不必要的时间成本。而 Scoop 可以幫助你統一安裝並管理常見的開發軟體，省去了手動下載安裝，配置環境變數等繁瑣步驟。

例如安裝 python 和 nodejs 只需要執行：

1
2

scoop install python
scoop install nodejs

安裝 Scoop

親測+官方安裝方法

微軟商店安裝最新版Powershell

打開PowerShell，輸入以下指令

1
2

Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser
Invoke-RestMethod -Uri https://get.scoop.sh | Invoke-Expression

出現下圖，即為安裝成功

Scoop 需要 Windows PowerShell 5.1 或者 PowerShell 作為運行環境，如果你使用的是 Windows 10 及以上版本，Windows PowerShell 是內建在系統中的。而 Windows 7 內建的 Windows PowerShell 版本過於陳舊，你需要手動安裝新版本的 PowerShell。

由於發現很多同學在設置 Windows 用戶時使用了中文用戶名，導致了用戶目錄也變成了中文名。如果按照 Scoop 的預設方式將軟體安裝到用戶目錄下，可能會造成部分軟體執行錯誤。所以這裡推薦安裝到自訂目錄，如果需要其他安裝方式請參考： ScoopInstaller/Install

1
2
3
4
5
6

# 設置 PowerShell 執行策略
Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser
# 下載安裝腳本
irm get.scoop.sh -outfile 'install.ps1'
# 執行安裝, --ScoopDir 參數指定 Scoop 安裝路徑
.\install.ps1 -ScoopDir 'C:\Scoop'

使用 Scoop

Scoop 的官方文件對於新手非常友善，相對於在此處贅述更推薦閱讀 官方文件 或 快速入門 。

常用指令

指令 作用
scoop bucket list 查看目前scoop安裝的所有倉庫
scoop search 用於搜尋軟體
scoop install 用於安裝軟體
scoop list 用於查看已安裝的軟體
scoop uninstall 用於解除安裝軟體
scoop bucket 用於管理倉庫
scoop update 用於更新軟體
scoop config proxy 為soop設置代理
scoop reset 用於切換軟體版本

Q&A

Scoop 能配置映像源嗎？

Scoop 社群僅維護安裝配置，所有的軟體都是從該軟體官方提供的下載連結進行下載，所以無法提供映像源。如果因為你的網路環境導致多次下載失敗，那麼你需要一點點 魔法。

為什麼找不到 Java8？

原因同上，官方已不再提供 Java8 的下載連結，推薦使用 ojdkbuild8 替代。

我需要安裝 python2 該如何操作？

對於已經過時棄用的軟體，Scoop 社群會將其從 ScoopInstaller/Main 中移除並將其添加到 ScoopInstaller/Versions 中。如果你需要這些軟體的話需要手動添加 bucket：

1
2

scoop bucket add versions
scoop install python27
