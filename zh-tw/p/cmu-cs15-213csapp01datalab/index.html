題目解析

第一題

題面

bitXor

使用僅允許的操作符 ～（按位取反）和 &（按位與），實現互斥或運算 x ^ y。例如，bitXor(4, 5) 應返回 1

思路

這裡暴力列舉法（數學歸納法？）發現任意兩個數 x,y 有性質一 x ^ y = (~x & y) | (x & ~y) ①

但是題目不準我們用 |，則我們可以發現性質二 x | y = ~(~x & ~y)②

最終答案

1
2
3
4
5
6
7

int bitXor(int x, int y)
{
  // 易得 x ^ y = (~x & y) | (x & ~y) ①
  // 且   x | y = ~(~x & ~y) ②
  // 得   x ^ y = ~(~(~x & y) & ~(x & ~y))
  return ~(~(~x & y) & ~(x & ~y));
}

第二題

題面

tmin

返回二進位制補碼錶示下的最小整數（即 0x80000000，對於32位系統是 -2³¹）。

思路

要求二進位制補碼錶示下的最小整數，即求只有符號位為1，其他為0的32位整數，

因此我們給出一個1並讓其左移32位，此時即為二進位制補碼錶示下的最小整數

最終答案

1
2
3
4
5
6
7

int tmin(void)
{
  // 32位二進位制數 為          0000 0000 0000 0000 0000 0000 0000 0000
  // 第32位為符號位 則最小為  1000 0000 0000 0000 0000 0000 0000 0000
  // 將1左移31位，此時則為最大的負數32位數
  return 1 << 31;
}

第三題

題面

isTmax

判斷輸入 x 是否等於二進位制補碼所能表示的最大正整數（即 0x7FFFFFFF，對於32位系統是 2³¹ - 1）。如果是，返回 1；否則返回 0。

思路

我們可以發現，二進位制補碼為最大正整數（0x7FFFFFFF）令其為x（依舊如夢令）​時，有性質 (x+1)^~x==0​，題目要求為最大整數時返回1，因此在式子前加多一個取反!(x+1)^~x==0

0x7FFFFFFF + 1 = 0x80000000
~0x7FFFFFFF = 0x80000000

但同時，-1（0xFFFFFFFF）也有這種性質

0xFFFFFFFF + 1 = 0x00000000
~0xFFFFFFFF = 0x00000000

則我們要特殊判斷，可以利用!!(x+1)是否為1判斷，如果為-1，經過此式子會變為1再變為0，其他數則是先變為0再變為1

最終答案

1
2
3
4

int isTmax(int x)
{
  return !((x + 1) ^ (~x)) & !!(x + 1);
}

第四題

題面

allOddBits

判斷一個32位整數中所有「奇數編號」的位（從0開始計數，即第1、3、5…31位）是否都為1。例如，0xAAAAAAAA 的二進位制奇數位全為1，應返回1。

思路

我們要判斷x是否所有奇數位（注意是從0開始編號的！！！）是否都為1，可以對所有奇數位進行按位與，之後互斥或，若互斥或後為0，則x所有奇數位都為1，若不為0，說明按位與的時候有一位以上的奇數位不為1，所以按位與後不為0

之後根據題目要求，將互斥或的結果取反

最終答案

1
2
3
4
5
6
7
8

int allOddBits(int x)
{
  int mask = 0x55;
  mask = mask | (mask << 8);
  mask = mask | (mask << 16);
  mask = mask << 1; // 因為從0開始計數
  return !((x & mask) ^ mask);
}

第五題

題面

negate

實現對整數 x 取負數，即返回 -x，符合二進位制補碼規則。

思路

比較簡單，這裡說一下個人怎麼理解的，因為負數的補碼比正數的補碼多1位（因為0屬於正數的補碼範圍），所以+1相當於消除了這個影響

最終答案

1
2
3
4

int negate(int x)
{
  return ~x + 1;
}

第六題

題面

isAsciiDigit

判斷輸入 x 是否是 ASCII 碼中表示數字字元 ‘0’ 到 ‘9’ 的值（即十六進位制 0x30 到 0x39，十進位制 48 到 57）。如果是，返回1；否則返回0。

思路

根據非負性判斷是否屬於這個區間，用x減去最小區間（0x30）然後右移31位判斷符號（int為32位，第32位為符號位，因此右移31位判斷符號）；再用最大區間（0x39）減去x，同上判斷符號，若x處於二者區間，則符號位上都為0，按位與的答案也為0，之後取反即為答案

這裡要注意用到上題的+負數的方法，因為題目要求不能直接減一個數字（式子：-x=~x+1）

最終答案

1
2
3
4
5
6
7
8

int isAsciiDigit(int x)
{
  int lower = x + (~0x30 + 1);
  int upper = 0x39 + (~x + 1);
  int lowerSign = lower >> 31; // 非負時為0
  int upperSign = upper >> 31; // 同上
  return !(lowerSign | upperSign);
}

第七題

題面

conditional

實現三元運算子 x ? y : z 的功能：如果 x 非零，返回 y；否則返回 z。不能使用條件語句，只能用位運算和算術操作。

思路

利用 !!x 將 x 轉換為 0 或 1，再通過取反加一（即 -!!x）構造全 0 或全 1 的掩碼 mask；

  • 當 x 非零時 mask 為全 1，返回 y，
  • 否則 mask 為全 0，返回 z。

最終答案

1
2
3
4
5

int conditional(int x, int y, int z)
{
  int mask = ~(!!x) + 1;
  return (mask & y) | (~mask & z);
}

第八題

題面

isLessOrEqual

判斷是否滿足 x <= y。如果成立，返回1；否則返回0。需考慮二進位制補碼下的溢位和符號問題。

思路

通過比較 x 和 y 的符號位以及 y - x 的符號，分情況判斷：

  • 若 x 為負、y 為正，則一定滿足；
  • 若同號，則看 y - x 是否非負（即無溢位時差值符號為 0）

從而正確處理溢位和符號問題。

最終答案

1
2
3
4
5
6
7
8

int isLessOrEqual(int x, int y)
{
  int signX = x >> 31;
  int signY = y >> 31;
  int yMinusX = y + (~x + 1);
  int signDiff = yMinusX >> 31;
  return (signX & !signY) | (!(signX ^ signY) & !signDiff);
}

第九題

題面

logicalNeg

實現邏輯非運算 ! 的功能：當 x == 0 時返回1，否則返回0。但不能使用 ! 操作符，只能用其他合法操作。

思路

利用 x 與其相反數～x + 1的符號位：

  • 當 x 為 0 時，兩者都為 0，符號位為 0；
  • 當 x 非 0 時，x 與 -x 必有一個為負，符號位為 1。

將兩者按位或後算術右移 31 位得到符號位，再加 1 即得邏輯非結果。

最終答案

1
2
3
4
5
6

int logicalNeg(int x)
{
  int negX = ~x + 1;
  int combined = x | negX;
  return (combined >> 31) + 1;
}

第十題

題面

howManyBits

計算在二進位制補碼錶示下，表示整數 x 所需的最少位數。例如：

12（二進位制 1100）需要5位（含符號位）；

-5 需要4位；

0 需要1位；

-1 的補碼全是1，只需1位；

0x80000000（最小負數）需要32位。

思路

先將 x 轉換為其絕對值（對負數按位取反），然後通過二分法快速定位最高有效位（MSB）的位置；所需位數為 MSB 位置加 1（數值位）再加 1（符號位），但 0 特殊處理為只需 1 位。

int howManyBits(int x)
{
  int sign = x >> 31;
  int y = (sign & ~x) | (~sign & x);
  int isZero = !y;
  int shift, msb;

  shift = (!!(y >> 16)) << 4;
  y >>= shift;
  msb = shift;

  shift = (!!(y >> 8)) << 3;
  y >>= shift;
  msb += shift;

  shift = (!!(y >> 4)) << 2;
  y >>= shift;
  msb += shift;

  shift = (!!(y >> 2)) << 1;
  y >>= shift;
  msb += shift;

  shift = !!(y >> 1);
  msb += shift;

  return msb + 2 + (~isZero + 1);
}

第十一題

題面

floatScale2

將一個單精度浮點數 f（以 unsigned int 形式傳入，表示其32位IEEE 754格式）乘以2，並返回結果的位級表示。若原數為 NaN（非數），則直接返回原值。

思路

乘以2相當於將浮點數的階碼加1：

  • 若為非規格化數（exp=0），則直接左移尾數一位；
  • 若為規格化數，則階碼加0x00800000；
  • 若原數是無窮大或NaN（exp全1），則返回原值；
  • 特別地，當階碼為0x7F000000（即254）時，加1會溢位為無窮大。

unsigned floatScale2(unsigned uf)
{
  unsigned sign = uf & 0x80000000;
  unsigned exp = uf & 0x7F800000;
  unsigned frac = uf & 0x007FFFFF;

  if (exp == 0x7F800000)
  {
    return uf;
  }

  if (exp == 0)
  {
    return sign | (frac << 1);
  }

  if (exp == 0x7F000000)
  {
    return sign | 0x7F800000;
  }

  return sign | (exp + 0x00800000) | frac;
}

第十二題

題面

floatFloat2Int

將一個單精度浮點數 f（以 unsigned int 傳入，表示其IEEE 754格式）轉換為整數 (int)f。如果該浮點數超出 int 表示範圍（包括無窮大或 NaN），則返回 0x80000000u（即 INT_MIN 的無符號形式）。

思路

根據 IEEE 754 格式提取符號、階碼和尾數：

  • 處理 NaN/Inf 返回 INT_MIN；非規格化或指數為負時值小於1，返回0；
  • 若指數 ≥31 則超出 int 範圍（包括 2³¹ 及以上），返回 INT_MIN；
  • 否則將隱含前導1的尾數按指數調整位數，再根據符號位決定是否取負。

當exp位上全為1時為無窮大，全為0時為無窮小；另外，因為exp上隱含了符號位，即第30位不代表符號，而是第30-23位都代表一個範圍，0-255，因此轉回Int型別時，需要-127

int floatFloat2Int(unsigned uf)
{
  unsigned sign = (uf >> 31) & 1;
  unsigned exp = (uf >> 23) & 0xFF;
  unsigned frac = uf & 0x7FFFFF;
  unsigned val, sig;
  int e;
  if (exp == 0xFF)
  {
    return 0x80000000u;
  }

  if (exp == 0)
  {
    return 0;
  }

  e = exp - 127;

  if (e < 0)
  {
    return 0;
  }

  sig = (1U << 23) | frac;

  if (e > 31)
  {
    return 0x80000000u;
  }

  if (e == 31)
  {
    if (frac != 0)
    {
      return 0x80000000u;
    }

    if (sign == 0)
    {
      return 0x80000000u;
    }
    else
    {
      return 0x80000000u;
    }
  }

  if (e >= 23)
  {
    val = sig << (e - 23);
  }
  else
  {
    val = sig >> (23 - e);
  }

  if (sign)
  {
    return (~val + 1u);
  }
  else
  {
    return val;
  }
}

第十三題

題面

floatPower2

計算 2.0^x（即 2 的 x 次方）的單精度浮點數的位級表示（作為 unsigned int 返回）。

  • 如果結果太小（低於規格化數範圍且無法用非規格化數表示），返回 0；
  • 如果結果太大（溢位），返回正無窮（+INF）的位表示。

思路

易知根據 IEEE 754 單精度浮點格式，2^x 的結果僅影響階碼和尾數：

  • 當 x 在 [-126, 127] 時為規格化數，階碼為 x+127，尾數為 0；
  • 當 x ∈ [-149, -127) 時為非規格化數，尾數最低位對應 2^{x+149}；
  • 超出範圍則返回 0 或 +∞。

IEEE規定，單精度浮點數，第31位代表符號位（0為正，1為負），第30-23位表示數值的數量級（即 2 的多少次方），第22-0位表示有效數字的小數部分。

unsigned floatPower2(int x)
{
  // 過小
  if (x < -149)
  {
    return 0;
  }

  // 非規格化
  if (x < -127)
  {
    int shift = x + 149;
    return 1U << shift;
  }

  // 過大
  if (x > 127)
  {
    return 0x7f800000;
  }

  // 規格化
  x += 127;
  return x << 23;
}

/*
 * bitXor - x^y using only ~ and &
 *   Example: bitXor(4, 5) = 1
 *   Legal ops: ~ &
 *   Max ops: 14
 *   Rating: 1
 */
int bitXor(int x, int y)
{
  // 易得 x ^ y = (~x & y) | (x & ~y) ①
  // 且   x | y = ~(~x & ~y) ②
  // 得   x ^ y = ~(~(~x & y) & ~(x & ~y))
  return ~(~(~x & y) & ~(x & ~y));
}

/*
 * tmin - return minimum two's complement integer
 *   Legal ops: ! ~ & ^ | + << >>
 *   Max ops: 4
 *   Rating: 1
 */
int tmin(void)
{
  // 32位二進位制數 為          0000 0000 0000 0000 0000 0000 0000 0000
  // 第32位為符號位 則最小為  1000 0000 0000 0000 0000 0000 0000 0000
  // 將1左移31位，此時則為最大的負數三十二位數
  return 1 << 31;
}

 * isTmax - returns 1 if x is the maximum, two's complement number,

 *   Legal ops: ! ~ & ^ | +

/*
 * allOddBits - return 1 if all odd-numbered bits in word set to 1
 *   where bits are numbered from 0 (least significant) to 31 (most significant)
 *   Examples allOddBits(0xFFFFFFFD) = 0, allOddBits(0xAAAAAAAA) = 1
 *   Legal ops: ! ~ & ^ | + << >>
 *   Max ops: 12
 *   Rating: 2
 */
int allOddBits(int x)
{
  int mask = 0x55;
  mask = mask | (mask << 8);
  mask = mask | (mask << 16);
  mask = mask << 1; // 因為從0開始計數
  return !((x & mask) ^ mask);
}

 *   Example: isAsciiDigit(0x35) = 1.
 *            isAsciiDigit(0x3a) = 0.

 *   Legal ops: ! ~ & ^ | + << >>
 *   Max ops: 15
 *   Rating: 3

int isAsciiDigit(int x)

  int upper = 0x39 + (~x + 1);

/*
 * conditional - same as x ? y : z
 *   Example: conditional(2,4,5) = 4
 *   Legal ops: ! ~ & ^ | + << >>
 *   Max ops: 16
 *   Rating: 3
 */
int conditional(int x, int y, int z)
{
  int mask = ~(!!x) + 1;
  return (mask & y) | (~mask & z);
}
/*
 * isLessOrEqual - if x <= y  then return 1, else return 0
 *   Example: isLessOrEqual(4,5) = 1.
 *   Legal ops: ! ~ & ^ | + << >>
 *   Max ops: 24
 *   Rating: 3
 */
int isLessOrEqual(int x, int y)
{
  int signX = x >> 31;
  int signY = y >> 31;
  int yMinusX = y + (~x + 1);
  int signDiff = yMinusX >> 31;
  return (signX & !signY) | (!(signX ^ signY) & !signDiff);
}

  int combined = x | negX;

/* howManyBits - return the minimum number of bits required to represent x in
 *             two's complement
 *  Examples: howManyBits(12) = 5
 *            howManyBits(298) = 10
 *            howManyBits(-5) = 4
 *            howManyBits(0)  = 1
 *            howManyBits(-1) = 1
 *            howManyBits(0x80000000) = 32
 *  Legal ops: ! ~ & ^ | + << >>
 *  Max ops: 90
 *  Rating: 4
 */
int howManyBits(int x)
{
  int sign = x >> 31;
  int y = (sign & ~x) | (~sign & x);
  int isZero = !y;
  int shift, msb;

  shift = (!!(y >> 16)) << 4;
  y >>= shift;
  msb = shift;

  shift = (!!(y >> 8)) << 3;
  y >>= shift;
  msb += shift;

  shift = (!!(y >> 4)) << 2;
  y >>= shift;
  msb += shift;

  shift = (!!(y >> 2)) << 1;
  y >>= shift;
  msb += shift;

  shift = !!(y >> 1);
  msb += shift;

  return msb + 2 + (~isZero + 1);
}

/*
 * floatScale2 - Return bit-level equivalent of expression 2*f for
 *   floating point argument f.
 *   Both the argument and result are passed as unsigned int's, but
 *   they are to be interpreted as the bit-level representation of
 *   single-precision floating point values.
 *   When argument is NaN, return argument
 *   Legal ops: Any integer/unsigned operations incl. ||, &&. also if, while
 *   Max ops: 30
 *   Rating: 4
 */
unsigned floatScale2(unsigned uf)
{
  unsigned sign = uf & 0x80000000;
  unsigned exp = uf & 0x7F800000;
  unsigned frac = uf & 0x007FFFFF;

  if (exp == 0x7F800000)
  {
    return uf;
  }

  if (exp == 0)
  {
    return sign | (frac << 1);
  }

  if (exp == 0x7F000000)
  {
    return sign | 0x7F800000;
  }

  return sign | (exp + 0x00800000) | frac;
}
/*
 * floatFloat2Int - Return bit-level equivalent of expression (int) f
 *   for floating point argument f.
 *   Argument is passed as unsigned int, but
 *   it is to be interpreted as the bit-level representation of a
 *   single-precision floating point value.
 *   Anything out of range (including NaN and infinity) should return
 *   0x80000000u.
 *   Legal ops: Any integer/unsigned operations incl. ||, &&. also if, while
 *   Max ops: 30
 *   Rating: 4
 */
int floatFloat2Int(unsigned uf)
{
  unsigned sign = (uf >> 31) & 1;
  unsigned exp = (uf >> 23) & 0xFF;
  unsigned frac = uf & 0x7FFFFF;
  unsigned val, sig;
  int e;
  if (exp == 0xFF)
  {
    return 0x80000000u;
  }

  if (exp == 0)
  {
    return 0;
  }

  e = exp - 127;

  if (e < 0)
  {
    return 0;
  }

  sig = (1U << 23) | frac;

  if (e > 31)
  {
    return 0x80000000u;
  }

  if (e == 31)
  {
    if (frac != 0)
    {
      return 0x80000000u;
    }

    if (sign == 0)
    {
      return 0x80000000u;
    }
    else
    {
      return 0x80000000u;
    }
  }

  if (e >= 23)
  {
    val = sig << (e - 23);
  }

  else
  {
    val = sig >> (23 - e);
  }

  if (sign)
  {
    return (~val + 1u);
  }
  else
  {
    return val;
  }
}
/*
 * floatPower2 - Return bit-level equivalent of the expression 2.0^x
 *   (2.0 raised to the power x) for any 32-bit integer x.
 *
 *   The unsigned value that is returned should have the identical bit
 *   representation as the single-precision floating-point number 2.0^x.
 *   If the result is too small to be represented as a denorm, return
 *   0. If too large, return +INF.
 *
 *   Legal ops: Any integer/unsigned operations incl. ||, &&. Also if, while
 *   Max ops: 30
 *   Rating: 4
 */
unsigned floatPower2(int x)
{
  // 過小
  if (x < -149)
  {
    return 0;
  }

  // 非規格化
  if (x < -127)
  {
    int shift = x + 149;
    return 1U << shift;
  }

  // 過大
  if (x > 127)
  {
    return 0x7f800000;
  }

  // 規格化
  x += 127;
  return x << 23;
}
