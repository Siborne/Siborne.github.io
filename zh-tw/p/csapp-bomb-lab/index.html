完整記錄 CMU CS:APP Bomb Lab 六個關卡的拆彈過程，逐行解讀 x86-64 組合語言程式碼，涵蓋函式傳參約定、迴圈與陣列、跳轉表、遞迴二分搜尋、位元運算字元映射、鏈結串列重組降序驗證等核心考點。

CMU CS15213-CSAPP
简体中文 English 日本語

這組合語言是真難熬。

Bomb Lab 是 CMU 15-213（CS:APP）課程中最經典的實驗之一。你要面對一個名為 bomb 的二進位可執行檔，它包含 6 個關卡，每關要求你輸入一個特定密碼。輸入錯誤，炸彈就會爆炸（程式印出 “BOOM!” 並扣分）。你手頭只有一份可執行檔和 GDB 除錯器，目標是反組譯並逆向推理出每一關的密碼。

本文將完整覆盤 6 個關卡的拆彈全過程，從組合語言程式碼逐行解讀到 GDB 實操技巧，再到如何將組合語言邏輯翻譯回 C 語言。

開始準備

在拆彈之前，先做好 GDB 環境設定和保命中斷點設定。

關閉 GDB 聯網下載（Ubuntu 使用者必做）

新版 Ubuntu 的 GDB 預設會聯網下載除錯符號，導致啟動極慢：

1

echo "set debuginfod enabled off" >> ~/.gdbinit

開局保命中斷點

每次進入 gdb bomb，第一時間打下兩個中斷點：

1
2

(gdb) b explode_bomb    # 炸彈想炸時，GDB 會立刻攔截掛起
(gdb) b phase_1         # 給目前關卡設中斷點（後續換成 phase_2, phase_3 等）

輸入流所有權：新手最易踩的坑

這是貫穿整個實驗最重要的概念——分清楚你目前在跟誰說話：

終端機顯示 你在跟誰說話 能輸入什麼
有 (gdb) 提示符 GDB 除錯器 除錯命令：c、r、disassemble、x/s 等
只有一個綠色閃爍游標 炸彈程式 拆彈密碼！絕不能在此輸入 GDB 命令

如果程式卡死或處於炸彈等待輸入狀態，隨時按 Ctrl + C 強行攔截程式，讓 (gdb) 提示符重新出現。

Phase 1：字串比對

考點：x86-64 函式傳參約定 + 記憶體字串檢視

第一關是最簡單的熱身關卡，只需找到隱藏在記憶體中的目標字串。

反組譯 phase_1，核心邏輯極其簡單：將你的輸入字串和記憶體中某個預設字串做比對，相同則通關。

(gdb) disassemble phase_1

0x0000000000400ee0 <+0>:  	sub    $0x8,%rsp
0x0000000000400ee4 <+4>: 	mov    $0x402400,%esi               # 關鍵！地址 0x402400 → 第2參數
0x0000000000400ee9 <+9>:  	call   0x401338 <strings_not_equal> # 呼叫字串比對函式
0x0000000000400eee <+14>: 	test   %eax,%eax                    # 回傳值：0 = 相等
0x0000000000400ef0 <+16>: 	je     0x400ef7 <phase_1+23>        # 回傳 0 → 通關
0x0000000000400ef2 <+18>: 	call   0x40143a <explode_bomb>      # 回傳非 0 → 爆炸
0x0000000000400ef7 <+23>: 	add    $0x8,%rsp
0x0000000000400efb <+27>: 	ret

流程解讀：

  1. mov $0x402400, %esi：根據 x86-64 函式傳參約定，%rsi/%esi 是第二個參數。strings_not_equal 的原型是 strings_not_equal(char *input, char *target)，所以 0x402400 就是目標字串的記憶體位址。
  2. call strings_not_equal：呼叫比對函式，如果兩個字串相同回傳 0，結果放入 %eax。
  3. test %eax, %eax + je：檢查回傳值是否為 0，是則跳轉通關，否則引爆。

考點速記：x86-64 函式傳參約定 —— %rdi（第1參數）、%rsi（第2參數）、%rdx（第3參數）、%rcx（第4參數）。回傳值一律放 %rax/%eax。

GDB 一秒破案：

1

(gdb) x/s 0x402400

螢幕上直接打出 Border relations with Canada have never been better.，這就是第一關密碼。

C 語言等價程式碼：

1
2
3
4

void phase_1(char *input) {
    if (strings_not_equal(input, "Border relations with Canada have never been better.") != 0) {
        explode_bomb();
    }
}

陣列偏移量計算：

組合語言中看不到 num[i]，只有 偏移量(%rsp)。以 %rsp 為基底位址，int 佔 4 位元組：

陣列項 下標 偏移量 組合語言寫法
num[0] 0 0×4=0 (%rsp)
num[1] 1 1×4=4 0x4(%rsp)
num[2] 2 2×4=8 0x8(%rsp)
num[3] 3 3×4=12 0xc(%rsp)
num[4] 4 4×4=16 0x10(%rsp)
num[5] 5 5×4=20 0x14(%rsp)
num[6] 6 6×4=24 0x18(%rsp)（哨兵，不存資料）

核心公式：位址 = 基底位址 + (下標 × 元素位元組數)

關鍵概念：ja vs jg

指令 全稱 比較方式 適用場景
ja Jump if Above 無號比較 所有位元當正數，負數會被當作巨大正數
jg Jump if Greater 有號比較 最高位元當符號位元，支援負數比較

這裡用了 ja，輸入負數時其補數 0xFFFFFFFF 在無號視角下是 4294967295，遠大於 7，直接觸發爆炸。

跳轉表定址公式：跳轉目標所在位址 = 表基底位址(0x402470) + (索引 × 8)

0x0000000000400ffe <+48>: 	call   0x400fce <func4>             # 遞迴
0x0000000000401003 <+53>: 	lea    0x1(%rax,%rax,1),%eax       # result = 2 × result + 1

關鍵最佳化：shr $0x1f, %ecx 取符號位元

組合語言中用 sar（算術右移）做除法，但 sar 在負數上會向下取整，而 C 語言整數除法要求向零取整：

運算式 C 語言要求 sar 直接算
15 / 2 7 7 ✓
-15 / 2 -7 -8 ✗

編譯器的微操：先 shr $0x1f 取符號位元（正數得 0，負數得 1），再 add 加到被除數上，然後 sar。這樣就修復了負數除法的偏差。

推導 num1：

如何讓 func4 回傳 0？

  • 走左半區：回傳值 = 2 × 子結果。子結果為 0 則還是 0，但需要多輪遞迴。
  • 走右半區：回傳值 = 2 × 子結果 + 1。最低位元永遠是 1，不可能湊出 0。
  • 直接命中 mid：回傳值直接 = 0，不需遞迴。

初始 low=0, high=14：mid = 0 + (14-0)/2 = 7。輸入 7，一發入魂。

註：純走左路遞迴也能得到 0 的值有 0、1、3、7，但 7 最直觀。

int func4(int val, int low, int high) {
    int mid = low + (high - low) / 2;
    if (mid > val) {
        return 2 * func4(val, low, mid - 1);       // 左半區
    } else if (mid < val) {
        return 2 * func4(val, mid + 1, high) + 1;  // 右半區
    } else {
        return 0;                                   // 命中！
    }
}

void phase_4(char *input) {
    int num1, num2;
    if (sscanf(input, "%d %d", &num1, &num2) != 2) { explode_bomb(); }
    if (num1 > 14) { explode_bomb(); }
    if (func4(num1, 0, 14) != 0) { explode_bomb(); }
    if (num2 != 0) { explode_bomb(); }
}

答案：7 0

核心公式

  • 陣列偏移量：位址 = 基底位址 + (下標 × 元素位元組數)
  • 跳轉表定址：跳轉目標所在位址 = 表基底位址 + (索引 × 8)（64 位元下指標佔 8 位元組）
  • sscanf 參數對應：第 3 參數 %rdx → 第一個 %d；第 4 參數 %rcx → 第二個 %d
  • ja vs jg：ja 是無號比較（Above），jg 是有號比較（Greater）
