2. 段落語法

要建立段落，請使用空白行將一行或多行文字進行分隔。

1
2

這是第一段的段落
這是第二段的段落

請不要在段落面前加入空格或者製表符（TAB）

6. 列表語法

可以將多個條目組織成有序或無序列表。

要建立有序列表，請在每個列表項前新增數字並緊跟一個英文句點。數字不必按數學順序排列，但是列表應當以數字 1 起始。

1
2
3
4

1. 第一件物品
2. 第二件物品
3. 第三件物品
4. LOLOLOLOL
  1. 第一件物品
  2. 第二件物品
  3. 第三件物品
  4. LOLOLOLOL

要建立無序列表，請在每個列表項前面新增破折號（-）、星號（*）或加號（+）。縮排一個或多個列表項可建立巢狀列表。注意跟符號之間有空格

1
2
3
4

- 第一件物品
- 第二件物品
- 第三件沒了
- 再看一下上一行
  • 第一件物品
  • 第二件物品
  • 第三屆沒了
  • 再看一下上一行

但是不能混用，例如：

7. 程式碼語法

一句話裡面摻一些程式碼

1

``Use `code` in your Markdown file.``

11. 跳脫字元語法

要顯示原本用於格式化 Markdown 文件的字元，請在字元前面新增反斜槓字元 \。

1

\* Without the backslash, this would be a bullet in an unordered list.

* Without the backslash, this would be a bullet in an unordered list.

特殊字元自動跳脫

在 HTML 檔案中，有兩個字元需要特殊處理： < 和 & 。 < 符號用於起始標籤，& 符號則用於標記 HTML 實體，如果你只是想要使用這些符號，你必須要使用實體的形式，像是 < 和 &。

例如：

1
2

http://images.google.com/images?num=30&q=larry+bird
http://images.google.com/images?num=30&q=larry+bird

12. 內嵌 HTML 標籤

HTML 的行級內聯標籤如 、 不受限制，可以在 Markdown 的段落、列表或是標題裡任意使用。依照個人習慣，甚至可以不用 Markdown 格式，而採用 HTML 標籤來格式化。例如：如果比較喜歡 HTML 的 或 標籤，可以直接使用這些標籤，而不用 Markdown 提供的連結或是圖片語法。當你需要更改元素的屬性時（例如為文字指定顏色或更改影象的寬度），使用 HTML 標籤更方便些。

HTML 行級內聯標籤和區塊標籤不同，在內聯標籤的範圍內，Markdown 的語法是可以解析的。

1

**這一段話既可以這麼加粗**，<strong>也可以這麼加粗。</strong>
