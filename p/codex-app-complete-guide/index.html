Codex APP 保姆级全攻略：从安装到自动化，一期精通

全面拆解 Codex APP 全部功能：沙箱权限、多项目并行、GPT Image 画图、计划模式、Git Worktree、云端运行、Skills/MCP、定时自动化与 Computer Use。

核心要点概括

  • Codex APP 是目前最强的 Codex 产品形态，免费额度高、功能全、不封号不限速
  • 沙箱机制：OS 级安全隔离，默认禁止访问沙箱外文件和联网，三档权限可选
  • 多项目并行：多项目、多对话同时跑，物理隔离互不干扰
  • 计划模式：先对齐再执行，避免 AI 理解偏差导致大量返工
  • Git Worktree：分支级并行开发，不同文件夹真正隔离
  • Skills/MCP：可复用专业能力包 + 标准化外部工具接入
  • 定时自动化：插件 + 定时任务 + MEMORY 经验积累，越用越稳

为什么选 Codex APP？

Codex 有四大产品形态，而 Codex APP 是目前最强的一个。相比 Claude Code：

  • 额度更高，免费账户也能用
  • 功能更全，内置浏览器、画图、插件市场、定时任务
  • 不会限速、封号、降智
  • 上手更快，安装即用

本文按 12 个章节，逐一拆解 Codex APP 的全部功能。

一、安装与初始化

准备工作

安装 Codex APP 前需要先装好三件套：

  • Git
  • Node.js
  • VS Code

安装步骤

  1. 前往 Codex 官网 下载安装包（支持 Windows / Mac）
  2. 一路下一步完成安装
  3. 启动后选择 ChatGPT 账户登录（免费账户即可）
  4. 首次进入选择你希望 Codex 处理的工作类型，Codex 会根据选择预装对应插件和 Skills
  5. 选择主要使用场景：编程 / 日常工作
  6. 点击初始化沙盒

Mac vs Windows：功能基本一致，唯一差异是 Computer Use（自动操作电脑）目前仅 Mac 支持。

二、基础使用

三栏布局

Codex APP 采用经典三栏布局：

  • 左侧：任务列表（项目 + 对话）
  • 中间：对话窗口
  • 右侧：多功能区域（浏览器、终端、文件树等）

项目管理

通过「添加新项目 → 使用现有文件夹」把本地文件夹注册为 Codex 项目。每个项目独立管理对话，互不干扰。

并行任务

Codex 支持多项目、多对话并行执行。任务列表中用图标标识状态：

  • 🔵 蓝色小点 → 已完成
  • 🟢 绿色标签 → 等待批准
  • 🔄 转圈图标 → 正在执行

对话管理

  • 新对话：Ctrl + N（Win）/ Cmd + N（Mac）
  • 搜索历史：Ctrl + G / Cmd + G（仅搜索标题，不搜索内容）
  • 归档/还原：点击归档按钮移除对话，在「设置 → 已归档对话」中可还原
  • 标题自动生成：每个对话标题由 AI 根据内容自动摘要，也可双击重命名

权限系统：沙箱机制

Codex 的权限系统全部围绕**沙箱（Sandbox）**展开，这是 Harness Engineering 概念的典型工程实现——用操作系统级别的机制，把 AI 的能力约束在可控范围内。

默认限制：

限制 说明
沙箱内文件 默认直接读写，不需要逐文件审批
沙箱外文件 禁止访问
联网 默认禁止

这两条硬性限制不是靠模型自觉，而是通过操作系统底层机制实现的（Mac 用 Seatbelt/Sandbox，Windows 有对应机制）。

三个权限档位：

档位 说明 推荐
人工审批 每次提权都需要手动确认 最安全但繁琐
自动审查 小模型自动审查低风险操作，高风险才人工确认 ✅ 推荐
完全访问 无视沙箱限制，可执行一切操作 ⚠️ 慎用

当 Codex 需要访问沙箱外文件或联网时，会发起「提权（Escalate）」申请。

上下文管理

  • 右上角圆圈显示当前上下文使用量
  • 超出限制时 Codex 自动压缩历史对话
  • 也可以输入 /compact 手动触发压缩
  • 经验法则：清空 > 压缩。完成一个任务后开新对话，让 AI 注意力集中

模型选择

  • 根据任务复杂度选择思考强度
  • 一般用最新模型（如 ChatGPT 5.5）
  • 快速模式：提速 50%，但消耗 2 倍额度

额度查看

「设置 → 剩余额度」中可以看到两个限额：

  • 5 小时限额
  • 周限额

任一到达上限即暂停使用，到重置时间后自动恢复。

三、画图

Codex 内置 GPT Image（当前最强 AI 生图模型），可以直接在对话中生成图片。

典型用法：

  • 生成网页配图、轮播图
  • 根据截图标注位置生成风格化地图
  • 保持多张图片的风格一致性

Steer（引导）功能

当 AI 执行方向跑偏时，不要让它继续错下去。点击对话中的引导按钮（或按 Ctrl + Enter），中途接管方向盘，纠正 AI 的执行方向。

设置中可选择新指令是「排队」还是「直接引导」，推荐默认排队 + 需要时手动点引导按钮。

四、计划模式

对于所有复杂任务，建议先开启计划模式（Plan Mode），确保和 AI 对齐颗粒度。

工作流程：

  1. 在对话窗口点击加号 → 开启「计划模式」
  2. 输入需求，Codex 会先用问题卡片跟你沟通细节
  3. Codex 输出完整工作计划
  4. 你审阅确认后，点击「实施此计划」
  5. Codex 执行并自动在右侧打开内置浏览器验证

计划模式的价值：避免 AI 理解偏差导致大量返工，尤其适合架构迁移、大功能开发等任务。

内置浏览器 + 批注

  • 右侧多功能区可打开内置浏览器预览项目
  • 点击「批注」按钮，选中页面元素添加评论，AI 会据此修改
  • 修改过程实时可见

五、代码管理

Codex APP 不是传统 IDE，不提供完整代码编辑功能。推荐配合 VS Code 使用。

Git 初始化

让 Codex 把项目初始化成 Git 仓库：

  • 自动创建 .gitignore，排除不需要的文件
  • 初始化完成后右上角出现 Git 相关按钮

配合 VS Code

点击右上角 VS Code 按钮一键打开项目，也可以在设置中指定默认 IDE。

GitHub 同步

让 Codex 帮你在 GitHub 创建仓库并推送代码，所有 Git/GitHub 操作都可以用对话完成。

进阶技巧一：对话分叉 + Git 回滚

当你后悔某次改动，想「当作无事发生」：

  1. 对话分叉（Fork）：在对话中找到改动前的位置，点击分叉按钮 → 派生到本地，得到一个不含改动的对话副本
  2. 代码回滚：在 VS Code 的 Source Control 中复制目标 commit hash，让 Codex 把代码回退到该状态

分叉只回滚对话历史，代码需要单独通过 Git 回滚。两者配合实现对话 + 代码的完全回滚。

进阶技巧二：Git Worktree

Worktree 本质是用 Git 创建新分支，并把分支代码复制到独立文件夹，实现多分支并行开发。

使用场景：

  1. 右键项目 → 创建永久工作树（如 customer-rating、store-info）
  2. 在不同工作树中并行开发不同功能，互不干扰
  3. 开发完成后，分别合并回主干
  4. 移除临时工作树

Worktree 的核心价值：不同分支位于不同文件夹，真正做到物理隔离的并行开发。

六、云端运行

当手头没有电脑，或想让任务在后台云端运行时：

前提条件：代码已同步到 GitHub。

操作流程：

  1. 推送本地代码到 GitHub
  2. 运行模式选择「关联 Codex Web」
  3. 点击「前往 Cloud」，输入仓库名和需求
  4. Codex 初始化云端环境 → 下载代码 → AI 分析 → 完成修改
  5. 点击「创建拉取请求」→ 代码以 PR 形式提交到 GitHub
  6. 审核通过后在 GitHub 上 Merge
  7. 回到本地 Sync Changes 同步最新代码

最佳场景：出门在外，用手机审批，让 Codex 云端完成任务。

七、记忆系统

每次新对话，AI 对项目的记忆都是空白的。复杂项目需要记忆系统来避免重复交代。

方式一：项目级 AGENTS.md

在项目根目录创建 AGENTS.md 文件，每次对话自动作为上下文注入。

可以手写，也可以让 Codex 通读项目后自动生成：

方式二：全局 AGENTS.md

「设置 → 个性化 → 自定义指令」中编辑，对所有项目生效。

文件位置：C:\Users\<用户名>\.codex\AGENTS.md

实用示例——防止误删文件：

实验性功能：启用记忆

设置中的「启用记忆」可以从聊天中自动提取记忆并带入新对话，目前仍是实验性功能。

八、插件与自动化

插件市场

左侧边栏 → 插件，分为两类：

类型 说明
插件 第三方服务的能力注入（GitHub、Gmail、Netlify 等）
技能（Skills） 带目录的专业能力说明书

示例：GitHub + Gmail 联动

  1. 安装 GitHub 插件和 Gmail 插件
  2. 授权登录
  3. 输入：/github 查看我 star 数前十的开源项目 + /gmail 发邮件给我自己做摘要

定时自动化

把上述流程做成定时任务：

1

把上述工作做成自动化，每周五下午四点发邮件给我

创建后可在「自动化」面板中：

  • 编辑执行频率（每周/每天/每小时）
  • 切换模型（简单任务用迷你模型即可）
  • 点击「立即运行」测试

执行过程中积累的经验会写入 MEMORY.md，帮助下一次执行更稳定。

更多自动化玩法

配合浏览器自动化或 Computer Use：

  • 每天汇总 Teams 聊天记录发工作日报
  • 定时打开网站签到
  • 定期抓取数据生成报告

九、Skills

Skills 是给 AI Agent 的专业技能包，本质上是带目录的说明书。把工作流、专业能力、规范封装成 Skill，让 Agent 执行特定任务时更稳定高效。

十、MCP

MCP（Model Context Protocol）是大模型的标准化工具箱，让 AI 能与外部服务交互。

入口

「设置 → MCP 服务器 → 添加服务器」

示例：Supabase MCP

Supabase 是开源免费的 PostgreSQL 云数据库。

  1. 在 Supabase 创建项目 → Connect → MCP 客户端 → 选择 Codex → 复制 URL
  2. Codex 中添加 MCP 服务器，传输方式选「流式 HTTP」，填入 URL
  3. 终端运行 codex mcp login supabase 完成授权
  4. 重启 Codex

之后就可以用对话操作数据库：

用户的表单数据从后端用 connection pool 方式写入

十一、电脑自动化（Computer Use）

⚠️ 目前仅 Mac 支持

安装 Computer Use 插件后，Codex 可以直接操作你的电脑：

  • 打开聊天软件找到老板发消息
  • 打开浏览器查看 GitHub 看板，汇总项目进度
  • 生成英文简报发送给老板

特点

  • 使用虚拟鼠标后台运行，不占用当前窗口
  • 可以编制成定时自动化任务（如每天下午五点自动发简报）
  • Mac 上建议开启「运行时防止系统休眠」
