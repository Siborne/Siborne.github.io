完整记录 CMU CS:APP Bomb Lab 六个关卡的拆弹过程，逐行解读 x86-64 汇编代码，涵盖函数传参约定、循环与数组、跳转表、递归二分查找、位运算字符映射、链表重组降序校验等核心考点。

CMU CS15213:CSAPP
English 繁體中文 日本語

这汇编是真难熬。

Bomb Lab 是 CMU 15-213（CS:APP）课程中最经典的实验之一。你要面对一个名为 bomb 的二进制可执行文件，它包含 6 个关卡，每关要求你输入一个特定密码。输入错误，炸弹就会爆炸（程序打印 “BOOM!” 并扣分）。你手头只有一份可执行文件和 GDB 调试器，目标是反汇编并逆向推理出每一关的密码。

本文将完整复盘 6 个关卡的拆弹全过程，从汇编代码逐行解读到 GDB 实操技巧，再到如何将汇编逻辑翻译回 C 语言。

开始准备

在拆弹之前，先做好 GDB 环境配置和保命断点设置。

关闭 GDB 联网下载（Ubuntu 用户必做）

新版 Ubuntu 的 GDB 默认会联网下载调试符号，导致启动极慢：

1

echo "set debuginfod enabled off" >> ~/.gdbinit

开局保命断点

每次进入 gdb bomb，第一时间打下两个断点：

1
2

(gdb) b explode_bomb    # 炸弹想炸时，GDB 会立刻拦截挂起
(gdb) b phase_1         # 给当前关卡设断点（后续换成 phase_2, phase_3 等）

输入流所有权：新手最易踩的坑

这是贯穿整个实验最重要的概念——分清楚你当前在跟谁说话：

终端显示 你在跟谁说话 能输入什么
有 (gdb) 提示符 GDB 调试器 调试命令：c、r、disassemble、x/s 等
只有一个绿色闪烁光标 炸弹程序 拆弹密码！绝不能在此输入 GDB 命令

如果程序卡死或处于炸弹等待输入状态，随时按 Ctrl + C 强行拦截程序，让 (gdb) 提示符重新出现。

Phase 1：字符串比对

考点：x86-64 函数传参约定 + 内存字符串查看

第一关是最简单的热身关卡，只需找到隐藏在内存中的目标字符串。

反汇编 phase_1，核心逻辑极其简单：将你的输入字符串和内存中某个预设字符串做比对，相同则通关。

(gdb) disassemble phase_1

0x0000000000400ee0 <+0>:  	sub    $0x8,%rsp
0x0000000000400ee4 <+4>: 	mov    $0x402400,%esi               # 关键！地址 0x402400 → 第2参数
0x0000000000400ee9 <+9>:  	call   0x401338 <strings_not_equal> # 调用字符串比对函数
0x0000000000400eee <+14>: 	test   %eax,%eax                    # 返回值：0 = 相等
0x0000000000400ef0 <+16>: 	je     0x400ef7 <phase_1+23>        # 返回 0 → 通关
0x0000000000400ef2 <+18>: 	call   0x40143a <explode_bomb>      # 返回非 0 → 爆炸
0x0000000000400ef7 <+23>: 	add    $0x8,%rsp
0x0000000000400efb <+27>: 	ret

流程解读：

  1. mov $0x402400, %esi：根据 x86-64 函数传参约定，%rsi/%esi 是第二个参数。strings_not_equal 的原型是 strings_not_equal(char *input, char *target)，所以 0x402400 就是目标字符串的内存地址。
  2. call strings_not_equal：调用比对函数，如果两个字符串相同返回 0，结果放入 %eax。
  3. test %eax, %eax + je：检查返回值是否为 0，是则跳转通关，否则引爆。

考点速记：x86-64 函数传参约定 —— %rdi（第1参数）、%rsi（第2参数）、%rdx（第3参数）、%rcx（第4参数）。返回值一律放 %rax/%eax。

GDB 一秒破案：

1

(gdb) x/s 0x402400

屏幕上直接打出 Border relations with Canada have never been better.，这就是第一关密码。

数组偏移量计算：

汇编中看不到 num[i]，只有 偏移量(%rsp)。以 %rsp 为基地址，int 占 4 字节：

数组项 下标 偏移量 汇编写法
num[0] 0 0×4=0 (%rsp)
num[1] 1 1×4=4 0x4(%rsp)
num[2] 2 2×4=8 0x8(%rsp)
num[3] 3 3×4=12 0xc(%rsp)
num[4] 4 4×4=16 0x10(%rsp)
num[5] 5 5×4=20 0x14(%rsp)
num[6] 6 6×4=24 0x18(%rsp)（哨兵，不存数据）

核心公式：地址 = 基地址 + (下标 × 元素字节数)

关键概念：ja vs jg

指令 全称 比较方式 适用场景
ja Jump if Above 无符号比较 所有位当正数，负数会被当作巨大正数
jg Jump if Greater 有符号比较 最高位当符号位，支持负数比较

这里用了 ja，输入负数时其补码 0xFFFFFFFF 在无符号视角下是 4294967295，远大于 7，直接触发爆炸。

跳转表寻址公式：跳转目标所在地址 = 表基地址(0x402470) + (索引 × 8)

0x0000000000400fee <+32>: 	add    %eax,%eax                   # result = 2 × result

# 分支 B：mid == val → 命中！
0x0000000000400ff2 <+36>: 	mov    $0x0,%eax                   # 直接返回 0
0x0000000000400ff9 <+43>: 	jge    0x401007 <func4+57>

# 分支 C：mid < val → 去右半区
0x0000000000400ffb <+45>: 	lea    0x1(%rcx),%esi              # low = mid + 1
0x0000000000400ffe <+48>: 	call   0x400fce <func4>             # 递归
0x0000000000401003 <+53>: 	lea    0x1(%rax,%rax,1),%eax       # result = 2 × result + 1

关键优化：shr $0x1f, %ecx 取符号位

汇编中用 sar（算术右移）做除法，但 sar 在负数上会向下取整，而 C 语言整数除法要求向零取整：

表达式 C 语言要求 sar 直接算
15 / 2 7 7 ✓
-15 / 2 -7 -8 ✗

编译器的微操：先 shr $0x1f 取符号位（正数得 0，负数得 1），再 add 加到被除数上，然后 sar。这样就修复了负数除法的偏差。

推导 num1：

如何让 func4 返回 0？

  • 走左半区：返回值 = 2 × 子结果。子结果为 0 则还是 0，但需要多轮递归。
  • 走右半区：返回值 = 2 × 子结果 + 1。最低位永远是 1，不可能凑出 0。
  • 直接命中 mid：返回值直接 = 0，不需递归。

初始 low=0, high=14：mid = 0 + (14-0)/2 = 7。输入 7，一发入魂。

注：纯走左路递归也能得到 0 的值有 0、1、3、7，但 7 最直观。

int func4(int val, int low, int high) {
    int mid = low + (high - low) / 2;
    if (mid > val) {
        return 2 * func4(val, low, mid - 1);       // 左半区
    } else if (mid < val) {
        return 2 * func4(val, mid + 1, high) + 1;  // 右半区
    } else {
        return 0;                                   // 命中！
    }
}

void phase_4(char *input) {
    int num1, num2;
    if (sscanf(input, "%d %d", &num1, &num2) != 2) { explode_bomb(); }
    if (num1 > 14) { explode_bomb(); }
    if (func4(num1, 0, 14) != 0) { explode_bomb(); }
    if (num2 != 0) { explode_bomb(); }
}

核心公式

  • 数组偏移量：地址 = 基地址 + (下标 × 元素字节数)
  • 跳转表寻址：跳转目标所在地址 = 表基地址 + (索引 × 8)（64 位下指针占 8 字节）
  • sscanf 参数对应：第 3 参数 %rdx → 第一个 %d；第 4 参数 %rcx → 第二个 %d
  • ja vs jg：ja 是无符号比较（Above），jg 是有符号比较（Greater）
