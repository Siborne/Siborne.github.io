题目解析

第一题

题面

bitXor

使用仅允许的操作符 ～（按位取反）和 &（按位与），实现异或运算 x ^ y。例如，bitXor(4, 5) 应返回 1

思路

这里暴力列举法（数学归纳法？）发现任意两个数x,y有性质一 x ^ y = (~x & y) | (x & ~y) ①

但是题目不准我们用 |，则我们可以发现性质二 x | y = ~(~x & ~y)②

最终答案

1
2
3
4
5
6
7

int bitXor(int x, int y)
{
  // 易得 x ^ y = (~x & y) | (x & ~y) ①
  // 且   x | y = ~(~x & ~y) ②
  // 得   x ^ y = ~(~(~x & y) & ~(x & ~y))
  return ~(~(~x & y) & ~(x & ~y));
}

第二题

题面

tmin

返回二进制补码表示下的最小整数（即 0x80000000，对于32位系统是 -2³¹）。

思路

要求二进制补码表示下的最小整数，即求只有符号位为1，其他为0的32位整数，

因此我们给出一个1并让其左移32位，此时即为二进制补码表示下的最小整数

最终答案

1
2
3
4
5
6
7

int tmin(void)
{
  // 32位二进制数 为          0000 0000 0000 0000 0000 0000 0000 0000
  // 第32位为符号位 则最小为  1000 0000 0000 0000 0000 0000 0000 0000
  // 将1左移31位，此时则为最大的负数32位数
  return 1 << 31;
}

第三题

题面

isTmax

判断输入 x 是否等于二进制补码所能表示的最大正整数（即 0x7FFFFFFF，对于32位系统是 2³¹ - 1）。如果是，返回 1；否则返回 0。

思路

我们可以发现，二进制补码为最大正整数（0x7FFFFFFF）令其为x（依旧如梦令）​时，有性质 (x+1)^~x==0​，题目要求为最大整数时返回1，因此在式子前加多一个取反!(x+1)^~x==0

0x7FFFFFFF + 1 = 0x80000000
~0x7FFFFFFF = 0x80000000

但同时，-1（0xFFFFFFFF）也有这种性质

0xFFFFFFFF + 1 = 0x00000000
~0xFFFFFFFF = 0x00000000

则我们要特殊判断，可以利用!!(x+1)是否为1判断，如果为-1，经过此式子会变为1再变为0，其他数则是先变为0再变为1

最终答案

1
2
3
4

int isTmax(int x)
{
  return !((x + 1) ^ (~x)) & !!(x + 1);
}

第四题

题面

allOddBits

判断一个32位整数中所有“奇数编号”的位（从0开始计数，即第1、3、5…31位）是否都为1。例如，0xAAAAAAAA 的二进制奇数位全为1，应返回1。

思路

我们要判断x是否所有奇数位（注意是从0开始编号的！！！）是否都为1，可以对所有奇数位进行按位与，之后异或，若异或后为0，则x所有奇数位都为1，若不为0，说明按位与的时候有一位以上的奇数位不为1，所以按位与后不为0

之后根据题目要求，将异或的结果取反

最终答案

1
2
3
4
5
6
7
8

int allOddBits(int x)
{
  int mask = 0x55;
  mask = mask | (mask << 8);
  mask = mask | (mask << 16);
  mask = mask << 1; // 因为从0开始计数
  return !((x & mask) ^ mask);
}

第五题

题面

negate

实现对整数 x 取负数，即返回 -x，符合二进制补码规则。

思路

比较简单，这里说一下个人怎么理解的，因为负数的补码比正数的补码多1位（因为0属于正数的补码范围），所以+1相当于消除了这个影响

最终答案

1
2
3
4

int negate(int x)
{
  return ~x + 1;
}

第六题

题面

isAsciiDigit

判断输入 x 是否是 ASCII 码中表示数字字符 ‘0’ 到 ‘9’ 的值（即十六进制 0x30 到 0x39，十进制 48 到 57）。如果是，返回1；否则返回0。

思路

根据非负性判断是否属于这个区间，用x减去最小区间（0x30）然后右移31位判断符号（int为32位，第32位为符号位，因此右移31位判断符号）；再用最大区间（0x39）减去x，同上判断符号，若x处于二者区间，则符号位上都为0，按位与的答案也为0，之后取反即为答案

这里要注意用到上题的+负数的方法，因为题目要求不能直接减一个数字（式子：-x=~x+1）

最终答案

1
2
3
4
5
6
7
8

int isAsciiDigit(int x)
{
  int lower = x + (~0x30 + 1);
  int upper = 0x39 + (~x + 1);
  int lowerSign = lower >> 31; // 非负时为0
  int upperSign = upper >> 31; // 同上
  return !(lowerSign | upperSign);
}

第七题

题面

conditional

实现三元运算符 x ? y : z 的功能：如果 x 非零，返回 y；否则返回 z。不能使用条件语句，只能用位运算和算术操作。

思路

利用 !!x 将 x 转换为 0 或 1，再通过取反加一（即 -!!x）构造全 0 或全 1 的掩码 mask；

  • 当 x 非零时 mask 为全 1，返回 y，
  • 否则 mask 为全 0，返回 z。

最终答案

1
2
3
4
5

int conditional(int x, int y, int z)
{
  int mask = ~(!!x) + 1;
  return (mask & y) | (~mask & z);
}

第八题

题面

isLessOrEqual

判断是否满足 x <= y。如果成立，返回1；否则返回0。需考虑二进制补码下的溢出和符号问题。

思路

通过比较 x 和 y 的符号位以及 y - x 的符号，分情况判断：

  • 若 x 为负、y 为正，则一定满足；
  • 若同号，则看 y - x 是否非负（即无溢出时差值符号为 0）

从而正确处理溢出和符号问题。

最终答案

1
2
3
4
5
6
7
8

int isLessOrEqual(int x, int y)
{
  int signX = x >> 31;
  int signY = y >> 31;
  int yMinusX = y + (~x + 1);
  int signDiff = yMinusX >> 31;
  return (signX & !signY) | (!(signX ^ signY) & !signDiff);
}

第九题

题面

logicalNeg

实现逻辑非运算 ! 的功能：当 x == 0 时返回1，否则返回0。但不能使用 ! 操作符，只能用其他合法操作。

思路

利用 x 与其相反数～x + 1的符号位：

  • 当 x 为 0 时，两者都为 0，符号位为 0；
  • 当 x 非 0 时，x 与 -x 必有一个为负，符号位为 1。

将两者按位或后算术右移 31 位得到符号位，再加 1 即得逻辑非结果。

最终答案

1
2
3
4
5
6

int logicalNeg(int x)
{
  int negX = ~x + 1;
  int combined = x | negX;
  return (combined >> 31) + 1;
}

第十题

题面

howManyBits

计算在二进制补码表示下，表示整数 x 所需的最少位数。例如：

12（二进制 1100）需要5位（含符号位）；

-5 需要4位；

0 需要1位；

-1 的补码全是1，只需1位；

0x80000000（最小负数）需要32位。

思路

先将 x 转换为其绝对值（对负数按位取反），然后通过二分法快速定位最高有效位（MSB）的位置；所需位数为 MSB 位置加 1（数值位）再加 1（符号位），但 0 特殊处理为只需 1 位。

int howManyBits(int x)
{
  int sign = x >> 31;
  int y = (sign & ~x) | (~sign & x);
  int isZero = !y;
  int shift, msb;

  shift = (!!(y >> 16)) << 4;
  y >>= shift;
  msb = shift;

  shift = (!!(y >> 8)) << 3;
  y >>= shift;
  msb += shift;

  shift = (!!(y >> 4)) << 2;
  y >>= shift;
  msb += shift;

  shift = (!!(y >> 2)) << 1;
  y >>= shift;
  msb += shift;

  shift = !!(y >> 1);
  msb += shift;

  return msb + 2 + (~isZero + 1);
}

第十一题

题面

floatScale2

将一个单精度浮点数 f（以 unsigned int 形式传入，表示其32位IEEE 754格式）乘以2，并返回结果的位级表示。若原数为 NaN（非数），则直接返回原值。

思路

乘以2相当于将浮点数的阶码加1：

  • 若为非规格化数（exp=0），则直接左移尾数一位；
  • 若为规格化数，则阶码加0x00800000；
  • 若原数是无穷大或NaN（exp全1），则返回原值；
  • 特别地，当阶码为0x7F000000（即254）时，加1会溢出为无穷大。

unsigned floatScale2(unsigned uf)
{
  unsigned sign = uf & 0x80000000;
  unsigned exp = uf & 0x7F800000;
  unsigned frac = uf & 0x007FFFFF;

  if (exp == 0x7F800000)
  {
    return uf;
  }

  if (exp == 0)
  {
    return sign | (frac << 1);
  }

  if (exp == 0x7F000000)
  {
    return sign | 0x7F800000;
  }

  return sign | (exp + 0x00800000) | frac;
}

第十二题

题面

floatFloat2Int

将一个单精度浮点数 f（以 unsigned int 传入，表示其IEEE 754格式）转换为整数 (int)f。如果该浮点数超出 int 表示范围（包括无穷大或 NaN），则返回 0x80000000u（即 INT_MIN 的无符号形式）。

思路

根据 IEEE 754 格式提取符号、阶码和尾数：

  • 处理 NaN/Inf 返回 INT_MIN；非规格化或指数为负时值小于1，返回0；
  • 若指数 ≥31 则超出 int 范围（包括 2³¹ 及以上），返回 INT_MIN；
  • 否则将隐含前导1的尾数按指数调整位数，再根据符号位决定是否取负。

当exp位上全为1时为无穷大，全为0时为无穷小；另外，因为exp上隐含了符号位，即第30位不代表符号，而是第30-23位都代表一个范围，0-255，因此转回Int类型时，需要-127

int floatFloat2Int(unsigned uf)
{
  unsigned sign = (uf >> 31) & 1;
  unsigned exp = (uf >> 23) & 0xFF;
  unsigned frac = uf & 0x7FFFFF;
  unsigned val, sig;
  int e;
  if (exp == 0xFF)
  {
    return 0x80000000u;
  }

  if (exp == 0)
  {
    return 0;
  }

  e = exp - 127;

  if (e < 0)
  {
    return 0;
  }

  sig = (1U << 23) | frac;

  if (e > 31)
  {
    return 0x80000000u;
  }

  if (e == 31)
  {
    if (frac != 0)
    {
      return 0x80000000u;
    }

    if (sign == 0)
    {
      return 0x80000000u;
    }
    else
    {
      return 0x80000000u;
    }
  }

  if (e >= 23)
  {
    val = sig << (e - 23);
  }
  else
  {
    val = sig >> (23 - e);
  }

  if (sign)
  {
    return (~val + 1u);
  }
  else
  {
    return val;
  }
}

第十三题

题面

floatPower2

计算 2.0^x（即 2 的 x 次方）的单精度浮点数的位级表示（作为 unsigned int 返回）。

  • 如果结果太小（低于规格化数范围且无法用非规格化数表示），返回 0；
  • 如果结果太大（溢出），返回正无穷（+INF）的位表示。

思路

易知根据 IEEE 754 单精度浮点格式，2^x 的结果仅影响阶码和尾数：

  • 当 x 在 [-126, 127] 时为规格化数，阶码为 x+127，尾数为 0；
  • 当 x ∈ [-149, -127) 时为非规格化数，尾数最低位对应 2^{x+149}；
  • 超出范围则返回 0 或 +∞。

IEEE规定，单精度浮点数，第31位代表符号位（0为正，1为负），第30-23位表示数值的数量级（即 2 的多少次方），第22-0位表示有效数字的小数部分。

unsigned floatPower2(int x)
{
  // 过小
  if (x < -149)
  {
    return 0;
  }

  // 非规格化
  if (x < -127)
  {
    int shift = x + 149;
    return 1U << shift;
  }

  // 过大
  if (x > 127)
  {
    return 0x7f800000;
  }

  // 规格化
  x += 127;
  return x << 23;
}

/*
 * bitXor - x^y using only ~ and &
 *   Example: bitXor(4, 5) = 1
 *   Legal ops: ~ &
 *   Max ops: 14
 *   Rating: 1
 */
int bitXor(int x, int y)
{
  // 易得 x ^ y = (~x & y) | (x & ~y) ①
  // 且   x | y = ~(~x & ~y) ②
  // 得   x ^ y = ~(~(~x & y) & ~(x & ~y))
  return ~(~(~x & y) & ~(x & ~y));
}

/*
 * tmin - return minimum two's complement integer
 *   Legal ops: ! ~ & ^ | + << >>
 *   Max ops: 4
 *   Rating: 1
 */
int tmin(void)
{
  // 32位二进制数 为          0000 0000 0000 0000 0000 0000 0000 0000
  // 第32位为符号位 则最小为  1000 0000 0000 0000 0000 0000 0000 0000
  // 将1左移31位，此时则为最大的负数三十二位数
  return 1 << 31;
}

/*
 * isTmax - returns 1 if x is the maximum, two's complement number,
 *     and 0 otherwise
 *   Legal ops: ! ~ & ^ | +
 *   Max ops: 10
 *   Rating: 1
 */
int isTmax(int x)
{
  return !((x + 1) ^ (~x)) & !!(x + 1);
}
/*
 * allOddBits - return 1 if all odd-numbered bits in word set to 1
 *   where bits are numbered from 0 (least significant) to 31 (most significant)
 *   Examples allOddBits(0xFFFFFFFD) = 0, allOddBits(0xAAAAAAAA) = 1
 *   Legal ops: ! ~ & ^ | + << >>
 *   Max ops: 12
 *   Rating: 2
 */
int allOddBits(int x)
{
  int mask = 0x55;
  mask = mask | (mask << 8);
  mask = mask | (mask << 16);
  mask = mask << 1; // 因为从0开始计数
  return !((x & mask) ^ mask);
}

/*
 * isAsciiDigit - return 1 if 0x30 <= x <= 0x39 (ASCII codes for characters '0' to '9')
 *   Example: isAsciiDigit(0x35) = 1.
 *            isAsciiDigit(0x3a) = 0.
 *            isAsciiDigit(0x05) = 0.
 *   Legal ops: ! ~ & ^ | + << >>
 *   Max ops: 15
 *   Rating: 3
 */
int isAsciiDigit(int x)
{
  int lower = x + (~0x30 + 1);
  int upper = 0x39 + (~x + 1);
  int lowerSign = lower >> 31; // 非负时为0
  int upperSign = upper >> 31; // 同上
  return !(lowerSign | upperSign);
}
/*
 * conditional - same as x ? y : z
 *   Example: conditional(2,4,5) = 4
 *   Legal ops: ! ~ & ^ | + << >>
 *   Max ops: 16
 *   Rating: 3
 */
int conditional(int x, int y, int z)
{
  int mask = ~(!!x) + 1;
  return (mask & y) | (~mask & z);
}
/*
 * isLessOrEqual - if x <= y  then return 1, else return 0
 *   Example: isLessOrEqual(4,5) = 1.
 *   Legal ops: ! ~ & ^ | + << >>
 *   Max ops: 24
 *   Rating: 3
 */
int isLessOrEqual(int x, int y)
{
  int signX = x >> 31;
  int signY = y >> 31;
  int yMinusX = y + (~x + 1);
  int signDiff = yMinusX >> 31;
  return (signX & !signY) | (!(signX ^ signY) & !signDiff);
}

/*
 * logicalNeg - implement the ! operator, using all of
 *              the legal operators except !
 *   Examples: logicalNeg(3) = 0, logicalNeg(0) = 1
 *   Legal ops: ~ & ^ | + << >>
 *   Max ops: 12
 *   Rating: 4
 */
int logicalNeg(int x)
{
  int negX = ~x + 1;
  int combined = x | negX;
  return (combined >> 31) + 1;
}
/* howManyBits - return the minimum number of bits required to represent x in
 *             two's complement
 *  Examples: howManyBits(12) = 5
 *            howManyBits(298) = 10
 *            howManyBits(-5) = 4
 *            howManyBits(0)  = 1
 *            howManyBits(-1) = 1
 *            howManyBits(0x80000000) = 32
 *  Legal ops: ! ~ & ^ | + << >>
 *  Max ops: 90
 *  Rating: 4
 */
int howManyBits(int x)
{
  int sign = x >> 31;
  int y = (sign & ~x) | (~sign & x);
  int isZero = !y;
  int shift, msb;

  shift = (!!(y >> 16)) << 4;
  y >>= shift;
  msb = shift;

  shift = (!!(y >> 8)) << 3;
  y >>= shift;
  msb += shift;

  shift = (!!(y >> 4)) << 2;
  y >>= shift;
  msb += shift;

  shift = (!!(y >> 2)) << 1;
  y >>= shift;
  msb += shift;

  shift = !!(y >> 1);
  msb += shift;

  return msb + 2 + (~isZero + 1);
}

/*
 * floatScale2 - Return bit-level equivalent of expression 2*f for
 *   floating point argument f.
 *   Both the argument and result are passed as unsigned int's, but
 *   they are to be interpreted as the bit-level representation of
 *   single-precision floating point values.
 *   When argument is NaN, return argument
 *   Legal ops: Any integer/unsigned operations incl. ||, &&. also if, while
 *   Max ops: 30
 *   Rating: 4
 */
unsigned floatScale2(unsigned uf)
{
  unsigned sign = uf & 0x80000000;
  unsigned exp = uf & 0x7F800000;
  unsigned frac = uf & 0x007FFFFF;

  if (exp == 0x7F800000)
  {
    return uf;
  }

  if (exp == 0)
  {
    return sign | (frac << 1);
  }

  if (exp == 0x7F000000)
  {
    return sign | 0x7F800000;
  }

  return sign | (exp + 0x00800000) | frac;
}
/*
 * floatFloat2Int - Return bit-level equivalent of expression (int) f
 *   for floating point argument f.
 *   Argument is passed as unsigned int, but
 *   it is to be interpreted as the bit-level representation of a
 *   single-precision floating point value.
 *   Anything out of range (including NaN and infinity) should return
 *   0x80000000u.
 *   Legal ops: Any integer/unsigned operations incl. ||, &&. also if, while
 *   Max ops: 30
 *   Rating: 4
 */
int floatFloat2Int(unsigned uf)
{
  unsigned sign = (uf >> 31) & 1;
  unsigned exp = (uf >> 23) & 0xFF;
  unsigned frac = uf & 0x7FFFFF;
  unsigned val, sig;
  int e;
  if (exp == 0xFF)
  {
    return 0x80000000u;
  }

  if (exp == 0)
  {
    return 0;
  }

  e = exp - 127;

  if (e < 0)
  {
    return 0;
  }

  sig = (1U << 23) | frac;

  if (e > 31)
  {
    return 0x80000000u;
  }

  if (e == 31)
  {
    if (frac != 0)
    {
      return 0x80000000u;
    }

    if (sign == 0)
    {
      return 0x80000000u;
    }
    else
    {
      return 0x80000000u;
    }
  }

  if (e >= 23)
  {
    val = sig << (e - 23);
  }

  else
  {
    val = sig >> (23 - e);
  }

  if (sign)
  {
    return (~val + 1u);
  }
  else
  {
    return val;
  }
}
/*
 * floatPower2 - Return bit-level equivalent of the expression 2.0^x
 *   (2.0 raised to the power x) for any 32-bit integer x.
 *
 *   The unsigned value that is returned should have the identical bit
 *   representation as the single-precision floating-point number 2.0^x.
 *   If the result is too small to be represented as a denorm, return
 *   0. If too large, return +INF.
 *
 *   Legal ops: Any integer/unsigned operations incl. ||, &&. Also if, while
 *   Max ops: 30
 *   Rating: 4
 */
unsigned floatPower2(int x)
{
  // 过小
  if (x < -149)
  {
    return 0;
  }

  // 非规格化
  if (x < -127)
  {
    int shift = x + 149;
    return 1U << shift;
  }

  // 过大
  if (x > 127)
  {
    return 0x7f800000;
  }

  // 规格化
  x += 127;
  return x << 23;
}
