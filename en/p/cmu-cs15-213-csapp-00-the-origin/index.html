CMU 15-213: CSAPP Course Introduction and Lab Environment Setup Guide

Course Introduction

CMU’s 15-213 (CSAPP) is widely recognized as the “legendary course” in computer science, renowned for its extensive content and extremely challenging projects. The course comprehensively covers assembly language, computer architecture, operating systems, program compilation and linking, concurrent programming, and networking fundamentals — a system-level introductory course with both depth and breadth. For self-learners, completing this course requires tremendous perseverance and solid programming fundamentals.

The accompanying textbook “Computer Systems: A Programmer’s Perspective” (abbreviated as CSAPP) was co-authored by Professor Randal E. Bryant, former head of CMU’s Computer Science Department, and David R. O’Hallaron. It has been adopted by numerous universities worldwide. This book is also the first computer systems textbook that many learners read page by page — though challenging, the rewards are enormous.

Peking University has introduced this course and offers “Introduction to Computer Systems,” but all CSAPP course materials, lab code, and lecture notes are freely available on its official website.

Due to the course’s significant influence, numerous lab (Project) reference answers circulate online. However, if you truly want to improve your systems programming abilities, it is strongly recommended to complete all labs independently, avoiding direct reference to third-party code. Persist through completion and hands-on practice, and your understanding of computer systems will achieve a qualitative leap.

Lab Environment Setup Tutorial

To successfully conduct CSAPP’s various labs (such as Data Lab, Bomb Lab, Malloc Lab, etc.), it is recommended to set up a clean, controllable Linux development environment in a virtual machine. Here are the detailed steps:

Step 1: Tool Preparation

Before starting, please download the following two files:

  • VMware Workstation Pro (Personal Free Version) Go to Broadcom’s official website to download the version suitable for your operating system.
  • Ubuntu 24.04 LTS Desktop ISO Image Filename is typically ubuntu-24.04.3-desktop-amd64.iso. It is recommended to download from University of Science and Technology of China Open Source Software Mirror or Tsinghua University Open Source Mirror for faster speeds.

Why Choose Ubuntu Desktop Version?

  • Built-in GUI: More friendly for learners migrating from Windows or macOS, allowing simultaneous use of terminal, browser, file manager, and text editor for documentation review, tutorial watching, or error message searching.
  • Complete community support: Most CSAPP lab tutorials (including videos from well-known Bilibili uploaders like “Jiuqu Langgan”) are demonstrated based on Ubuntu with GUI.
  • Supports “Minimal Installation”: Although the complete image is about 6GB, you can select “Minimal Installation” during installation, keeping only browser and basic terminal for lightweight convenience.

Why Other Versions Are Not Recommended?

  • live-server-amd64.iso: Server version without GUI, command-line only operation, not friendly for beginners.
  • .torrent / .zsync: Only download seeds or verification files, not system images.
  • netboot.tar.gz: For network boot installation, complex process, not suitable for virtual machine beginners.
  • WSL-related files: Designed specifically for Windows Subsystem for Linux, cannot be used in VMware.

Step 2: Create Virtual Machine

  1. Open VMware, click “Create a New Virtual Machine”, select “Typical (Recommended)”.

  2. For installation source, select “I will install the operating system later” (allows manual hardware configuration adjustment, avoiding permission or path issues from easy installation).

  3. Guest operating system selection: Linux → Ubuntu 64-bit.

  4. Configure key hardware parameters:

    • Memory: Recommended to allocate 4GB or more (if host memory is 16GB).
    • Processor: Set to 2 or 4 cores, and ensure virtualization engine (Intel VT-x / AMD-V) is enabled.
    • Hard Disk: At least 40GB, select “Store virtual disk as a single file” to improve I/O performance.
    • Network Adapter: Use NAT mode to allow virtual machine internet access through host.

Step 3: Install Ubuntu

Start the virtual machine and begin installation process:

  • Language: Recommended to select English, to adapt to CSAPP’s technical context in advance.
  • Installation Type: Check “Minimal installation” to avoid installing unnecessary office suites.
  • Disk Partitioning: Select “Erase disk and install Ubuntu”.
  • User Setup: Fill in username and password. For convenience, you can directly use “123456” as password.

Note: Unless specifically mentioned, always click Next.

After installation completes, restart to enter Ubuntu desktop environment.

This process may take a while, please be patient.

Step 4: Configure CSAPP Lab Development Environment

Even after seeing the desktop, you still need to install necessary development tools via terminal. Press Ctrl + Alt + T to open terminal and execute the following commands sequentially:

1. Update System Software Sources 

1

sudo apt update && sudo apt upgrade -y

2. Install Compilation and Debugging Tools 

1

sudo apt install build-essential gdb gcc-multilib g++-multilib -y

Step 5: Enable SSH Service (For Remote Interaction)

To conveniently connect to virtual machine through host terminal (such as Windows Terminal, iTerm2, or VS Code Remote), it is recommended to enable SSH service.

1. Install OpenSSH Server

Ubuntu Desktop version only includes SSH client by default, server needs manual installation:

1
2

sudo apt update
sudo apt install openssh-server -y

Verify SSH service is running normally:

1

sudo systemctl status ssh

If output contains green active (running), service has started successfully.

2. Obtain Virtual Machine IP Address

Execute the following command in terminal to view network interface information:

1

ip addr

Find network interface named ens33 (or eth0), its corresponding inet field (such as 192.168.x.x) is the virtual machine’s LAN IP address. Subsequently, you can SSH login to virtual machine through this address from host, for example:

1

ssh username@192.168.x.x

至此，你的CSAPP实验环境已完全就绪。接下来可从CSAPP官网下载各实验代码框架，正式开启系统编程之旅。
