Problem Walkthrough

Problem 1

Description

bitXor

Using only the allowed operators ~ (bitwise NOT) and & (bitwise AND), implement the XOR operation x ^ y. For example, bitXor(4, 5) should return 1.

Approach

By brute-force enumeration (mathematical induction?), we can discover that for any two numbers x and y, property one holds: x ^ y = (~x & y) | (x & ~y) (1)

But the problem does not allow us to use |, so we can discover property two: x | y = ~(~x & ~y) (2)

Final Answer

1
2
3
4

6

int bitXor(int x, int y)
{
  // It is easy to see that x ^ y = (~x & y) | (x & ~y) (1)
  // And   x | y = ~(~x & ~y) (2)
  // Therefore   x ^ y = ~(~(~x & y) & ~(x & ~y))
  return ~(~(~x & y) & ~(x & ~y));
}

Problem 2

Description

tmin

Return the minimum integer representable in two’s complement (i.e., 0x80000000, which is -2^31 for a 32-bit system).

Approach

To find the minimum integer in two’s complement representation, we need a 32-bit integer where only the sign bit is 1 and all other bits are 0.

Therefore, we take 1 and left-shift it by 31 bits to obtain the minimum integer in two’s complement representation.

Final Answer

1
2
3
4
5
6
7

int tmin(void)
{
  // A 32-bit binary number is   0000 0000 0000 0000 0000 0000 0000 0000
  // Bit 32 is the sign bit, so minimum is  1000 0000 0000 0000 0000 0000 0000 0000
  // Left-shift 1 by 31 bits to get the largest negative 32-bit number
  return 1 << 31;
}

Problem 3

Description

isTmax

Determine whether the input x equals the maximum positive integer representable in two’s complement (i.e., 0x7FFFFFFF, which is 2^31 - 1 for a 32-bit system). If so, return 1; otherwise return 0.

Approach

We can observe that for the maximum positive integer in two’s complement (0x7FFFFFFF), denoted as x, the property (x+1)^~x==0 holds. The problem requires returning 1 when x is the maximum integer, so we add a negation in front: !(x+1)^~x==0

0x7FFFFFFF + 1 = 0x80000000
~0x7FFFFFFF = 0x80000000

However, -1 (0xFFFFFFFF) also satisfies this property:

0xFFFFFFFF + 1 = 0x00000000
~0xFFFFFFFF = 0x00000000

So we need a special check, using whether !!(x+1) equals 1. If x is -1, this expression becomes 1 then 0; for other numbers, it becomes 0 then 1.

Final Answer

1
2
3
4

int isTmax(int x)
{
  return !((x + 1) ^ (~x)) & !!(x + 1);
}

Problem 4

Description

allOddBits

Determine whether all “odd-numbered” bits (counting from 0, i.e., bits 1, 3, 5, …, 31) of a 32-bit integer are set to 1. For example, 0xAAAAAAAA has all odd bits set to 1 and should return 1.

Approach

We need to determine whether all odd bits (note: counting starts from 0!!!) of x are 1. We can perform a bitwise AND with all odd positions, then XOR it. If the XOR result is 0, then all odd bits of x are 1. If it is not 0, it means at least one odd-position bit was not 1 during the bitwise AND.

Then, as required by the problem, negate the XOR result.

Final Answer

1
2
3

int allOddBits(int x)
{
  int mask = 0x55;
  mask = mask | (mask << 8);
  mask = mask | (mask << 16);
  mask = mask << 1; // Because counting starts from 0
  return !((x & mask) ^ mask);
}

Problem 5

Description

negate

Implement the negation of integer x, i.e., return -x, following the rules of two’s complement.

Approach

This one is relatively simple. Here is my personal understanding: since the two’s complement range for negative numbers has one more value than positive numbers (because 0 belongs to the positive range of two’s complement), adding 1 eliminates this offset.

Final Answer

int negate(int x)
{
  return ~x + 1;
}

Problem 6

Description

isAsciiDigit

Determine whether the input x is the ASCII value for a digit character from ‘0’ to ‘9’ (i.e., hex 0x30 to 0x39, decimal 48 to 57). If so, return 1; otherwise return 0.

Approach

Use non-negativity to determine whether x falls within this range. Subtract the lower bound (0x30) from x, then right-shift by 31 bits to check the sign (int is 32 bits, with bit 32 being the sign bit, so right-shifting by 31 bits checks the sign). Then subtract x from the upper bound (0x39) and check the sign in the same way. If x lies within the range, both sign bits will be 0, the bitwise OR will also be 0, and negating it gives us the answer.

Note that we need to use the negation method from the previous problem, since the problem disallows directly subtracting a number (formula: -x = ~x + 1).

Final Answer

1

int isAsciiDigit(int x)
{
  int lower = x + (~0x30 + 1);
  int upper = 0x39 + (~x + 1);
  int lowerSign = lower >> 31; // 0 when non-negative
  int upperSign = upper >> 31; // same as above
  return !(lowerSign | upperSign);
}

Problem 7

Description

conditional

Implement the ternary operator x ? y : z: if x is non-zero, return y; otherwise return z. Conditional statements are not allowed — only bitwise and arithmetic operations may be used.

Approach

Use !!x to convert x to 0 or 1, then construct a mask of all 0s or all 1s through bitwise NOT and adding 1 (i.e., -!!x).

  • When x is non-zero, the mask is all 1s, and y is returned;
  • Otherwise the mask is all 0s, and z is returned.

Final Answer

1
2
3
4

int conditional(int x, int y, int z)
{
  int mask = ~(!!x) + 1;
  return (mask & y) | (~mask & z);
}

Problem 8

Description

isLessOrEqual

Determine whether x <= y. If true, return 1; otherwise return 0. Must account for overflow and sign issues in two’s complement.

Approach

By comparing the sign bits of x and y along with the sign of y - x, handle different cases:

  • If x is negative and y is positive, the condition is definitely satisfied;
  • If they have the same sign, check whether y - x is non-negative (i.e., when there is no overflow, the difference’s sign bit is 0).

This correctly handles overflow and sign issues.

Final Answer

1

int isLessOrEqual(int x, int y)
{
  int signX = x >> 31;
  int signY = y >> 31;
  int yMinusX = y + (~x + 1);
  int signDiff = yMinusX >> 31;
  return (signX & !signY) | (!(signX ^ signY) & !signDiff);
}

Problem 9

Description

logicalNeg

Implement the logical NOT operation !: when x == 0, return 1; otherwise return 0. The ! operator itself may not be used — only other legal operations are allowed.

Approach

Use the sign bits of x and its negation ~x + 1:

  • When x is 0, both are 0, so the sign bit is 0;
  • When x is non-zero, one of x or -x must be negative, so the sign bit is 1.

Bitwise-OR the two together, then arithmetically right-shift by 31 bits to get the sign bit, and add 1 to obtain the logical NOT result.

Final Answer

1
2
3
4
5
6

int logicalNeg(int x)
{
  int negX = ~x + 1;
  int combined = x | negX;
  return (combined >> 31) + 1;
}

Problem 10

Description

howManyBits

Compute the minimum number of bits required to represent the integer x in two’s complement. For example:

  • 12 (binary 1100) requires 5 bits (including the sign bit);
  • -5 requires 4 bits;
  • 0 requires 1 bit;
  • -1 (all 1s in two’s complement) requires only 1 bit;
  • 0x80000000 (the minimum negative number) requires 32 bits.

Approach

First convert x to its absolute value (bitwise NOT for negative numbers), then use binary search to quickly locate the position of the Most Significant Bit (MSB). The required number of bits is the MSB position plus 1 (value bits) plus 1 (sign bit), with 0 handled as a special case requiring only 1 bit.

int howManyBits(int x)
{
  int sign = x >> 31;
  int y = (sign & ~x) | (~sign & x);
  int isZero = !y;
  int shift, msb;

  shift = (!!(y >> 16)) << 4;
  y >>= shift;
  msb = shift;

  shift = (!!(y >> 8)) << 3;
  y >>= shift;
  msb += shift;

  shift = (!!(y >> 4)) << 2;
  y >>= shift;
  msb += shift;

  shift = (!!(y >> 2)) << 1;
  y >>= shift;
  msb += shift;

  shift = !!(y >> 1);
  msb += shift;

  return msb + 2 + (~isZero + 1);
}

Problem 11

Description

floatScale2

Multiply a single-precision floating-point number f (passed as unsigned int, representing its 32-bit IEEE 754 format) by 2, and return the bit-level representation of the result. If the original value is NaN (Not a Number), return the original value unchanged.

Approach

Multiplying by 2 is equivalent to adding 1 to the floating-point exponent:

  • If it is a denormalized number (exp == 0), left-shift the mantissa by one bit;
  • If it is a normalized number, add 0x00800000 to the exponent;
  • If the original value is infinity or NaN (exp is all 1s), return the original value;
  • Specifically, when the exponent is 0x7F000000 (i.e., 254), adding 1 causes an overflow to infinity.

unsigned floatScale2(unsigned uf)
{
  unsigned sign = uf & 0x80000000;
  unsigned exp = uf & 0x7F800000;
  unsigned frac = uf & 0x007FFFFF;

  if (exp == 0x7F800000)
  {
    return uf;
  }

  if (exp == 0)
  {
    return sign | (frac << 1);
  }

  if (exp == 0x7F000000)
  {
    return sign | 0x7F800000;
  }

  return sign | (exp + 0x00800000) | frac;
}

Problem 12

Description

floatFloat2Int

Convert a single-precision floating-point number f (passed as unsigned int, representing its IEEE 754 format) to an integer (int)f. If the floating-point number exceeds the representable range of int (including infinity or NaN), return 0x80000000u (i.e., the unsigned form of INT_MIN).

Approach

Extract the sign, exponent, and mantissa according to the IEEE 754 format:

  • Handle NaN/Inf by returning INT_MIN; for denormalized values or when the exponent is negative (value < 1), return 0;
  • If the exponent is >= 31, it exceeds the int range (including 2^31 and above) — return INT_MIN;
  • Otherwise, adjust the mantissa (with the implicit leading 1) according to the exponent, then determine whether to negate based on the sign bit.

When the exponent bits are all 1s, it represents infinity; when they are all 0s, it represents values approaching zero. Additionally, because the exponent field has an implicit bias, i.e., bit 30 does not independently represent the sign — rather, bits 30-23 together represent a range from 0 to 255 — when converting back to int, one must subtract 127.

int floatFloat2Int(unsigned uf)
{
  unsigned sign = (uf >> 31) & 1;
  unsigned exp = (uf >> 23) & 0xFF;
  unsigned frac = uf & 0x7FFFFF;
  unsigned val, sig;
  int e;
  if (exp == 0xFF)
  {
    return 0x80000000u;
  }

  if (exp == 0)
  {
    return 0;
  }

  e = exp - 127;

  if (e < 0)
  {
    return 0;
  }

  sig = (1U << 23) | frac;

  if (e > 31)
  {
    return 0x80000000u;
  }

  if (e == 31)
  {
    if (frac != 0)
    {
      return 0x80000000u;
    }

    if (sign == 0)
    {
      return 0x80000000u;
    }
    else
    {
      return 0x80000000u;
    }
  }

  if (e >= 23)
  {
    val = sig << (e - 23);
  }
  else
  {
    val = sig >> (23 - e);
  }

  if (sign)
  {
    return (~val + 1u);
  }
  else
  {
    return val;
  }
}

Problem 13

Description

floatPower2

Compute the bit-level representation (returned as unsigned int) of the single-precision floating-point number 2.0^x (i.e., 2 raised to the power x).

  • If the result is too small (below the normalized range and not representable as a denormalized number), return 0;
  • If the result is too large (overflow), return the bit representation of positive infinity (+INF).

Approach

It is easy to see that, according to the IEEE 754 single-precision floating-point format, the result of 2^x only affects the exponent and mantissa:

  • When x is in [-126, 127], it is a normalized number with exponent x+127 and mantissa 0;
  • When x is in [-149, -127), it is a denormalized number, with the lowest bit of the mantissa corresponding to 2^{x+149};
  • When out of range, return 0 or +infinity.

IEEE specifies that for single-precision floating-point numbers, bit 31 represents the sign bit (0 for positive, 1 for negative), bits 30-23 represent the magnitude (i.e., the power of 2), and bits 22-0 represent the fractional part of the significand.

unsigned floatPower2(int x)
{
  // Too small
  if (x < -149)
  {
    return 0;
  }

  // Denormalized
  if (x < -127)
  {
    int shift = x + 149;
    return 1U << shift;
  }

  // Too large
  if (x > 127)
  {
    return 0x7f800000;
  }

  // Normalized
  x += 127;
  return x << 23;
}

/*
 * bitXor - x^y using only ~ and &
 *   Example: bitXor(4, 5) = 1
 *   Legal ops: ~ &
 *   Max ops: 14
 *   Rating: 1
 */
int bitXor(int x, int y)
{
  // It is easy to see that x ^ y = (~x & y) | (x & ~y) (1)
  // And   x | y = ~(~x & ~y) (2)
  // Therefore   x ^ y = ~(~(~x & y) & ~(x & ~y))
  return ~(~(~x & y) & ~(x & ~y));
}

/*
 * tmin - return minimum two's complement integer
 *   Legal ops: ! ~ & ^ | + << >>
 *   Max ops: 4
 *   Rating: 1
 */
int tmin(void)
{
  // A 32-bit binary number is   0000 0000 0000 0000 0000 0000 0000 0000
  // Bit 32 is the sign bit, so minimum is  1000 0000 0000 0000 0000 0000 0000 0000
  // Left-shift 1 by 31 bits to get the largest negative 32-bit number
  return 1 << 31;
}
// 2
/*
 * isTmax - returns 1 if x is the maximum, two's complement number,
 *     and 0 otherwise
 *   Legal ops: ! ~ & ^ | +
 *   Max ops: 10
 *   Rating: 1
 */
int isTmax(int x)
{
  return !((x + 1) ^ (~x)) & !!(x + 1);
}
/*
 * allOddBits - return 1 if all odd-numbered bits in word set to 1
 *   where bits are numbered from 0 (least significant) to 31 (most significant)
 *   Examples allOddBits(0xFFFFFFFD) = 0, allOddBits(0xAAAAAAAA) = 1
 *   Legal ops: ! ~ & ^ | + << >>
 *   Max ops: 12
 *   Rating: 2
 */
int allOddBits(int x)
{
  int mask = 0x55;
  mask = mask | (mask << 8);
  mask = mask | (mask << 16);
  mask = mask << 1; // Because counting starts from 0
  return !((x & mask) ^ mask);
}
/*
 * negate - return -x
 *   Example: negate(1) = -1.
 *   Legal ops: ! ~ & ^ | + << >>
 *   Max ops: 5
 *   Rating: 2
 */
int negate(int x)
{
  return ~x + 1;
}

/*
 * isAsciiDigit - return 1 if 0x30 <= x <= 0x39 (ASCII codes for characters '0' to '9')
 *   Example: isAsciiDigit(0x35) = 1.
 *            isAsciiDigit(0x3a) = 0.
 *            isAsciiDigit(0x05) = 0.
 *   Legal ops: ! ~ & ^ | + << >>
 *   Max ops: 15
 *   Rating: 3
 */
int isAsciiDigit(int x)
{
  int lower = x + (~0x30 + 1);
  int upper = 0x39 + (~x + 1);
  int lowerSign = lower >> 31; // 0 when non-negative
  int upperSign = upper >> 31; // same as above
  return !(lowerSign | upperSign);
}
/*
 * conditional - same as x ? y : z
 *   Example: conditional(2,4,5) = 4
 *   Legal ops: ! ~ & ^ | + << >>
 *   Max ops: 16
 *   Rating: 3
 */
int conditional(int x, int y, int z)
{
  int mask = ~(!!x) + 1;
  return (mask & y) | (~mask & z);
}
/*
 * isLessOrEqual - if x <= y  then return 1, else return 0
 *   Example: isLessOrEqual(4,5) = 1.
 *   Legal ops: ! ~ & ^ | + << >>
 *   Max ops: 24
 *   Rating: 3
 */
int isLessOrEqual(int x, int y)
{
  int signX = x >> 31;
  int signY = y >> 31;
  int yMinusX = y + (~x + 1);
  int signDiff = yMinusX >> 31;
  return (signX & !signY) | (!(signX ^ signY) & !signDiff);
}
// 4
/*
 * logicalNeg - implement the ! operator, using all of
 *              the legal operators except !
 *   Examples: logicalNeg(3) = 0, logicalNeg(0) = 1
 *   Legal ops: ~ & ^ | + << >>
 *   Max ops: 12
 *   Rating: 4
 */
int logicalNeg(int x)
{
  int negX = ~x + 1;
  int combined = x | negX;
  return (combined >> 31) + 1;
}
/* howManyBits - return the minimum number of bits required to represent x in
 *             two's complement
 *  Examples: howManyBits(12) = 5
 *            howManyBits(298) = 10
 *            howManyBits(-5) = 4
 *            howManyBits(0)  = 1
 *            howManyBits(-1) = 1
 *            howManyBits(0x80000000) = 32
 *  Legal ops: ! ~ & ^ | + << >>
 *  Max ops: 90
 *  Rating: 4
 */
int howManyBits(int x)
{
  int sign = x >> 31;
  int y = (sign & ~x) | (~sign & x);
  int isZero = !y;
  int shift, msb;

  shift = (!!(y >> 16)) << 4;
  y >>= shift;
  msb = shift;

  shift = (!!(y >> 8)) << 3;
  y >>= shift;
  msb += shift;

  shift = (!!(y >> 4)) << 2;
  y >>= shift;
  msb += shift;

  shift = (!!(y >> 2)) << 1;
  y >>= shift;
  msb += shift;

  shift = !!(y >> 1);
  msb += shift;

  return msb + 2 + (~isZero + 1);
}

/*
 * floatScale2 - Return bit-level equivalent of expression 2*f for
 *   floating point argument f.
 *   Both the argument and result are passed as unsigned int's, but
 *   they are to be interpreted as the bit-level representation of
 *   single-precision floating point values.
 *   When argument is NaN, return argument
 *   Legal ops: Any integer/unsigned operations incl. ||, &&. also if, while
 *   Max ops: 30
 *   Rating: 4
 */
unsigned floatScale2(unsigned uf)
{
  unsigned sign = uf & 0x80000000;
  unsigned exp = uf & 0x7F800000;
  unsigned frac = uf & 0x007FFFFF;

  if (exp == 0x7F800000)
  {
    return uf;
  }

  if (exp == 0)
  {
    return sign | (frac << 1);
  }

  if (exp == 0x7F000000)
  {
    return sign | 0x7F800000;
  }

  return sign | (exp + 0x00800000) | frac;
}
/*
 * floatFloat2Int - Return bit-level equivalent of expression (int) f
 *   for floating point argument f.
 *   Argument is passed as unsigned int, but
 *   it is to be interpreted as the bit-level representation of a
 *   single-precision floating point value.
 *   Anything out of range (including NaN and infinity) should return
 *   0x80000000u.
 *   Legal ops: Any integer/unsigned operations incl. ||, &&. also if, while
 *   Max ops: 30
 *   Rating: 4
 */
int floatFloat2Int(unsigned uf)
{
  unsigned sign = (uf >> 31) & 1;
  unsigned exp = (uf >> 23) & 0xFF;
  unsigned frac = uf & 0x7FFFFF;
  unsigned val, sig;
  int e;
  if (exp == 0xFF)
  {
    return 0x80000000u;
  }

  if (exp == 0)
  {
    return 0;
  }

  e = exp - 127;

  if (e < 0)
  {
    return 0;
  }

  sig = (1U << 23) | frac;

  if (e > 31)
  {
    return 0x80000000u;
  }

  if (e == 31)
  {
    if (frac != 0)
    {
      return 0x80000000u;
    }

    if (sign == 0)
    {
      return 0x80000000u;
    }
    else
    {
      return 0x80000000u;
    }
  }

  if (e >= 23)
  {
    val = sig << (e - 23);
  }

  else
  {
    val = sig >> (23 - e);
  }

  if (sign)
  {
    return (~val + 1u);
  }
  else
  {
    return val;
  }
}
/*
 * floatPower2 - Return bit-level equivalent of the expression 2.0^x
 *   (2.0 raised to the power x) for any 32-bit integer x.
 *
 *   The unsigned value that is returned should have the identical bit
 *   representation as the single-precision floating-point number 2.0^x.
 *   If the result is too small to be represented as a denorm, return
 *   0. If too large, return +INF.
 *
 *   Legal ops: Any integer/unsigned operations incl. ||, &&. Also if, while
 *   Max ops: 30
 *   Rating: 4
 */
unsigned floatPower2(int x)
{
  // Too small
  if (x < -149)
  {
    return 0;
  }

  // Denormalized
  if (x < -127)
  {
    int shift = x + 149;
    return 1U << shift;
  }

  // Too large
  if (x > 127)
  {
    return 0x7f800000;
  }

  // Normalized
  x += 127;
  return x << 23;
}
