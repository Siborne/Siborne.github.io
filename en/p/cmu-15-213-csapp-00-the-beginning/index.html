CMU 15-213: CSAPP Course Introduction and Lab Environment Setup Guide

Course Introduction

CMU’s 15-213 (CSAPP) is widely recognized as the “cornerstone course” in the field of computer science, renowned for its breadth of content and extremely challenging projects. The course comprehensively covers core topics such as assembly language, computer architecture, operating systems, program compilation and linking, concurrent programming, and networking fundamentals. It is a systems-level introductory course that combines both depth and breadth. For self-learners, completing this course requires tremendous perseverance and a solid programming foundation.

The course’s companion textbook, Computer Systems: A Programmer’s Perspective (abbreviated as CSAPP), was co-authored by Professor Randal E. Bryant, former department head of CMU’s Computer Science Department, and David R. O’Hallaron. It has been adopted by numerous universities worldwide. For many learners, this book is also the first computer systems textbook they read page by page — challenging, but immensely rewarding.

Peking University has adopted this course and offers Introduction to Computer Systems, but all CSAPP course materials, lab code, and lecture notes are freely available on its official website.

Due to the course’s immense influence, a large number of project reference solutions circulate online. However, if you truly want to enhance your systems programming skills, it is strongly recommended that you complete all labs independently and avoid directly referencing third-party code. Persist through the course and complete the hands-on work, and your understanding of computer systems will undergo a qualitative leap.

Lab Environment Setup Tutorial

To successfully carry out CSAPP’s various labs (such as Data Lab, Bomb Lab, Malloc Lab, etc.), it is recommended to set up a clean, controllable Linux development environment in a virtual machine. Below are the detailed steps:

Step 1: Prepare the Tools

Before you begin, download the following two files:

  • VMware Workstation Pro (Personal Free Edition) Go to the Broadcom official website and download the version suitable for your operating system.
  • Ubuntu 24.04 LTS Desktop Edition ISO Image The filename is typically ubuntu-24.04.3-desktop-amd64.iso. It is recommended to download from the University of Science and Technology of China Open Source Mirror or the Tsinghua University Open Source Mirror for faster download speeds.

Why Choose Ubuntu Desktop Edition?

  • Comes with a GUI (Graphical User Interface): More friendly for learners migrating from Windows or macOS. You can simultaneously use the terminal, browser, file manager, and text editor, making it convenient to consult documentation, watch instructional videos, or search for error messages.
  • Excellent Community Support: The vast majority of CSAPP lab tutorials (including videos by well-known Bilibili creators such as “九曲阑干”) are demonstrated using Ubuntu with a GUI.
  • Supports “Minimal Installation”: Although the full image is about 6GB, you can select “Minimal installation” during the installation process, retaining only the browser and basic terminal — balancing lightness with convenience.

Why Are Other Versions Not Recommended?

  • live-server-amd64.iso: Server edition, no GUI, pure command-line operation — not beginner-friendly.
  • .torrent / .zsync: These are merely download seeds or checksum files, not system images.
  • netboot.tar.gz: Used for network boot installation — the process is complex and unsuitable for virtual machine beginners.
  • WSL-related files: Designed specifically for Windows Subsystem for Linux and cannot be used in VMware.

Step 2: Create the Virtual Machine

  1. Open VMware, click “Create a New Virtual Machine”, and select “Typical (recommended)”.

  2. In the installation source options, choose “Install operating system later” (this allows manual adjustment of hardware configuration and avoids permission or path issues caused by Easy Install).

  3. Guest operating system selection: Linux → Ubuntu 64-bit.

  4. Configure key hardware parameters:

    • Memory: It is recommended to allocate 4GB or more (if the host has 16GB of RAM).
    • Processors: Set to 2 or 4 cores, and ensure virtualization engine (Intel VT-x / AMD-V) is enabled.
    • Hard Disk: At least 40GB, choose “Store virtual disk as a single file” to improve I/O performance.
    • Network Adapter: Use NAT mode so the virtual machine can access the internet through the host.

Step 3: Install Ubuntu

Start the virtual machine and begin the installation process:

  • Language: It is recommended to choose English to get used to the technical context of CSAPP early on.
  • Installation Type: Check “Minimal installation” to avoid installing unnecessary office suites.
  • Disk Partitioning: Choose “Erase disk and install Ubuntu”.
  • Set Up User: Fill in your username and password. For convenience, you can simply use “123456” as the password.

Note: Unless specifically mentioned, just keep clicking Next.

After installation is complete, restart to enter the Ubuntu desktop environment.

This process may take a while — please be patient.

Step 4: Configure the CSAPP Lab Development Environment

Even after reaching the desktop, you still need to install the necessary development toolchain via the terminal. Press Ctrl + Alt + T to open the terminal and execute the following commands in order:

1. Update System Package Sources 

1

sudo apt update && sudo apt upgrade -y

2. Install Compilation and Debugging Tools 

1

sudo apt install build-essential gdb gcc-multilib g++-multilib -y

Step 5: Enable SSH Service (for Convenient Remote Interaction)

To facilitate connecting to the virtual machine from your host terminal (e.g., Windows Terminal, iTerm2, or VS Code Remote) later on, it is recommended to enable the SSH service.

1. Install OpenSSH Server

Ubuntu Desktop Edition only includes the SSH client by default — you need to manually install the server:

1
2

sudo apt update
sudo apt install openssh-server -y

Verify that the SSH service is running properly:

1

sudo systemctl status ssh

If the output contains a green active (running), it means the service has started successfully.

2. Obtain the Virtual Machine IP Address

Execute the following command in the terminal to view network interface information:

1

ip addr

Locate the network interface named ens33 (or eth0), whose corresponding inet field (e.g., 192.168.x.x) is the virtual machine’s LAN IP address. You can later use this address to SSH into the virtual machine from your host, for example:

1

ssh username@192.168.x.x

At this point, your CSAPP lab environment is fully ready. You can now download the lab code frameworks from the CSAPP official website and officially begin your systems programming journey.
