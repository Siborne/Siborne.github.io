CMU 15-213: CSAPP コース紹介と実験環境構築ガイド

コース紹介

CMU の 15-213（CSAPP）は、コンピュータサイエンス分野で広く認められた「伝説の名授業」であり、その広範な内容と非常に難易度の高いプロジェクトで知られています。アセンブリ言語、コンピュータアーキテクチャ、オペレーティングシステム、プログラムのコンパイルとリンク、並行プログラミング、ネットワーク基礎などのコアテーマを包括的にカバーし、深さと広さを兼ね備えたシステムレベルの入門コースです。独学者にとって、このコースを修了するには強い意志と確かなプログラミング基礎が必要です。

このコースの教科書『Computer Systems: A Programmer’s Perspective』（略称 CSAPP）は、CMU コンピュータサイエンス学部の元学部長 Randal E. Bryant 教授と David R. O’Hallaron 氏の共著で、世界中の多くの大学で採用されています。この本は、多くの学習者にとって初めて1ページずつ精読するコンピュータシステムの教科書でもあります——難しいですが、得られるものは非常に大きいです。

北京大学はこのコースを導入し『コンピュータシステム入門』（Introduction to Computer Systems）を開設していますが、CSAPP の全コース資料、実験コード、講義資料はすべて公式サイトで無料で入手できます。

コースの影響力が非常に大きいため、インターネット上には実験（Project）の参考答案が多数出回っています。しかし、システムプログラミング能力を本当に向上させたいのであれば、すべての実験を独立して完了し、第三者のコードを直接参照することを避けるよう強くお勧めします。最後まで学び、実践を重ねることで、コンピュータシステムへの理解が質的に飛躍するでしょう。

引用：CS 独学ガイド - CMU 15-213: CSAPP

実験環境構築チュートリアル

CSAPP の各実験（Data Lab、Bomb Lab、Malloc Lab など）を円滑に進めるために、仮想マシンにクリーンで制御可能な Linux 開発環境を構築することを推奨します。以下は詳細な手順です：

ステップ1：ツールの準備

開始する前に、以下の2つのファイルをダウンロードしてください：

  • VMware Workstation Pro（個人無料版） Broadcom 公式サイトからご使用の OS に対応するバージョンをダウンロードしてください。
  • Ubuntu 24.04 LTS デスクトップ版 ISO イメージ ファイル名は通常 ubuntu-24.04.3-desktop-amd64.iso です。 中国科学技術大学オープンソースミラーサイト または 清華大学オープンソースミラーサイト からのダウンロードを推奨します（より高速です）。

なぜ Ubuntu デスクトップ版を選ぶのか？

  • GUI が付属：Windows や macOS から移行したばかりの学習者にとってより使いやすく、ターミナル、ブラウザ、ファイルマネージャ、テキストエディタを同時に使用でき、ドキュメントの参照、チュートリアル動画の視聴、エラーメッセージの検索が容易です。
  • コミュニティサポートが充実：ほとんどの CSAPP 実験チュートリアル（Bilibili の「九曲闌干」などの有名クリエイターの動画を含む）は、GUI 付き Ubuntu でのデモンストレーションに基づいています。
  • 「最小インストール」に対応：完全なイメージは約 6GB ですが、インストール時に “Minimal installation” をチェックすることで、ブラウザと基本ターミナルのみを保持し、軽量さと利便性を両立できます。

他のバージョンが推奨されない理由

  • live-server-amd64.iso：サーバー版、GUI なし、純粋なコマンドライン操作、初心者には不向き。
  • .torrent / .zsync：ダウンロード用のトレントまたは検証ファイルであり、システムイメージではありません。
  • netboot.tar.gz：ネットワークブートインストール用で、手順が複雑、仮想マシン初心者には不向き。
  • WSL 関連ファイル：Windows Subsystem for Linux 専用に設計されており、VMware では使用できません。

ステップ2：仮想マシンの作成

  1. VMware を起動し、「新しい仮想マシンの作成」 をクリック、「標準（推奨）」 を選択します。

  2. インストールソースのオプションで、「OS を後でインストール」 を選択（ハードウェア設定を手動調整しやすく、簡易インストールによる権限やパスの問題を回避します）。

  3. ゲスト OS の選択：Linux → Ubuntu 64-bit。

  4. 主要なハードウェアパラメータの設定：

    • メモリ：4GB 以上を推奨（ホストのメモリが 16GB の場合）。
    • プロセッサ：2 または 4 コアに設定し、仮想化エンジン（Intel VT-x / AMD-V） が有効であることを確認。
    • ハードディスク：少なくとも 40GB、「仮想ディスクを単一ファイルとして保存」 を選択して I/O パフォーマンスを向上。
    • ネットワークアダプタ：NAT モード を使用し、仮想マシンがホスト経由でインターネットにアクセスできるようにします。

ステップ3：Ubuntu のインストール

仮想マシンを起動し、インストールを開始します：

  • 言語：English を選択することを推奨。CSAPP の技術的文脈に早く慣れるためです。
  • インストールタイプ：“Minimal installation”（最小インストール）にチェックを入れ、不要なオフィススイートのインストールを回避。
  • ディスクパーティション：“Erase disk and install Ubuntu”（ディスクを消去して Ubuntu をインストール）を選択。
  • ユーザー設定：ユーザー名とパスワードを入力。簡単のため、パスワードを “123456” に設定しても構いません。

注意：特に記載がない限り、Next を押し続ければ進めます。

インストール完了後、再起動すると Ubuntu デスクトップ環境に入ります。

このプロセスには時間がかかる場合があります。しばらくお待ちください。

ステップ4：CSAPP 実験開発環境の設定

デスクトップが表示されても、ターミナルから必要な開発ツールチェーンをインストールする必要があります。Ctrl + Alt + T を押してターミナルを開き、以下のコマンドを順に実行します：

1. システムソフトウェアソースの更新 

1

sudo apt update && sudo apt upgrade -y

2. コンパイル・デバッグツールのインストール 

1

sudo apt install build-essential gdb gcc-multilib g++-multilib -y

ステップ5：SSH サービスの有効化（リモート操作の利便性向上）

後続でホストのターミナル（Windows Terminal、iTerm2、VS Code Remote など）から仮想マシンに接続しやすくするために、SSH サービスの有効化を推奨します。

1. OpenSSH サーバーのインストール

Ubuntu デスクトップ版にはデフォルトで SSH クライアントのみが含まれており、サーバーを手動でインストールする必要があります：

1
2

sudo apt update
sudo apt install openssh-server -y

SSH サービスが正常に動作しているか確認：

1

sudo systemctl status ssh

出力に緑色の active (running) が含まれていれば、サービスは正常に起動しています。

2. 仮想マシンの IP アドレス取得

ターミナルで以下のコマンドを実行してネットワークインターフェース情報を表示：

1

ip addr

ens33（または eth0）というネットワークインターフェースを見つけ、対応する inet フィールド（例：192.168.x.x）が仮想マシンの LAN IP アドレスです。このアドレスを使用して、後続でホストから SSH で仮想マシンにログインできます。例：

1

ssh username@192.168.x.x

これで、CSAPP 実験環境の準備が完全に整いました。次は CSAPP 公式サイト から各実験のコードフレームワークをダウンロードし、正式にシステムプログラミングの旅を始めましょう。
